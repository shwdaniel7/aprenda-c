while: repita enquanto a condição valer

O while testa a condição antes de cada volta: se for "falso" (zero) logo de cara, o corpo é pulado — pode nem executar uma vez. Note o padrão clássico: variável de controle, teste, e atualização da variável dentro do corpo.

Código — while
#include <stdio.h>

int main(void)
{
    int contador = 1;
    int soma = 0;

    while (contador <= 10) {
        soma += contador;
        contador++;
    }

    printf("soma de 1 a 10: %d\n", soma);
    return 0;
}
Saída esperada
soma de 1 a 10: 55

do-while: garanta ao menos uma execução

O do-while testa a condição depois do corpo — o corpo roda sempre pelo menos uma vez. É perfeito para menus: você mostra as opções e só pergunta de novo se a resposta foi inválida.

Código — do-while
#include <stdio.h>

int main(void)
{
    int escolha;

    do {
        printf("1) Ver saldo\n");
        printf("2) Depositar\n");
        printf("3) Sair\n");
        printf("Escolha: ");
        scanf("%d", &escolha);
    } while (escolha != 3);

    printf("Ate mais!\n");
    return 0;
}

for: o laço com contador

O for concentra a mecânica do contador em uma linha: for (inicialização; condição; passo). Tudo já é organizado para repetir "das tantas vezes até um valor". Como todos os laços de C aceitam apenas int como condição, o padrão de percorrer 0..n fica comum em todo código real.

Código — for
#include <stdio.h>

int main(void)
{
    int i;

    printf(" i  | i*i\n");
    printf("----+----\n");
    for (i = 1; i <= 5; i++) {
        printf("%3d | %3d\n", i, i * i);
    }
    return 0;
}
Saída esperada
 i  | i*i
----+----
  1 |   1
  2 |   4
  3 |   9
  4 |  16
  5 |  25

Loops infinitos, break e continue

Um for (;;) roda para sempre — útil quando a saída depende de um sinal lido de fora. Para sair no meio, break encerra o laço imediatamente; continue pula para a próxima volta (pulando o resto do corpo).

Código — controle do laço
#include <stdio.h>

int main(void)
{
    int n, soma = 0;

    printf("Digite numeros (0 encerra, negativos sao ignorados):\n");
    for (;;) {
        printf("> ");
        scanf("%d", &n);
        if (n == 0) {
            break;
        }
        if (n < 0) {
            continue;
        }
        soma += n;
    }

    printf("soma: %d\n", soma);
    return 0;
}
Saída esperada
Digite numeros (0 encerra, negativos sao ignorados):
> 5
> -3
> 2
> 0
soma: 7

Loops aninhados e a tabuada

Um laço dentro de outro forma loops aninhados: para cada volta do externo, o interno roda por inteiro. É assim que se percorre linhas × colunas — como a tabuada:

Código — aninhados
#include <stdio.h>

int main(void)
{
    int i, j;

    for (i = 1; i <= 9; i++) {
        for (j = 1; j <= 9; j++) {
            printf("%3d", i * j);
        }
        printf("\n");
    }
    return 0;
}

Contador vs condicional — e a vírgula no for

Escolha o laço pelo tipo de repetição, não pela aparência:

  • Número conhecido de voltas — for (tabuada, percorrer 1..n).
  • Repetir enquanto uma condição mudar por dados externos — while (processar até o 0).
  • Garantir ao menos uma passagem — do-while (menus).
  • Quem decide o fim do laço dentro do corpo ou lendo entrada — while ou for (;;) com break.
  • No for, vírgulas separam múltiplas instruções na inicialização ou no passo: for (i = 0, j = 10; i < j; i++, j--).

Programa: soma da série harmônica

Laços fazem o trabalho "pesado" com números de ponto flutuante: somar 1 + 1/2 + 1/3 + ... + 1/n. Repare no 1.0 / i: sem o .0, a divisão seria inteira e cada termo viraria 0 (menos o primeiro).

Código — serie.c
#include <stdio.h>

int main(void)
{
    int i, n;
    double soma = 0.0;

    printf("Quantos termos? ");
    scanf("%d", &n);

    for (i = 1; i <= n; i++) {
        soma += 1.0 / i;
    }

    printf("soma da serie 1 + 1/2 + ... + 1/%d = %.6f\n", n, soma);
    return 0;
}
Saída esperada
Quantos termos? 5
soma da serie 1 + 1/2 + ... + 1/5 = 2.283333

Programa: verificação de número primo

Aqui o laço testa uma propriedade e um break interrompe a busca na primeira evidência. i * i <= n limita o teste à raiz quadrada do número — sem biblioteca matemática.

Código — primo.c
#include <stdio.h>

int main(void)
{
    int n, i, eh_primo = 1;

    printf("Digite um numero: ");
    scanf("%d", &n);

    if (n < 2) {
        eh_primo = 0;
    } else {
        for (i = 2; i * i <= n; i++) {
            if (n % i == 0) {
                eh_primo = 0;
                break;
            }
        }
    }

    if (eh_primo) {
        printf("%d e primo\n", n);
    } else {
        printf("%d nao e primo\n", n);
    }
    return 0;
}
Saída esperada
Digite um numero: 17
17 e primo

✏️ Exercícios

Nível 2

Exercício 1.06.1

Com um for, imprima todos os números pares de 0 a 20, um por linha.

Dica: Comece em 0 e incremente de 2 em 2, ou teste i % 2 == 0.

Ver solução
#include <stdio.h>

int main(void)
{
    int i;

    for (i = 0; i <= 20; i += 2) {
        printf("%d\n", i);
    }
    return 0;
}
Nível 2

Exercício 1.06.2

Leia números inteiros e vá somando até que o usuário digite o valor 0 (o 0 não entra na soma). Imprima o total. Use while.

Dica: Padrão "sentinela": só pare quando o número digitado for 0.

Ver solução
#include <stdio.h>

int main(void)
{
    int n, soma = 0;

    printf("Digite numeros (0 encerra):\n");
    printf("> ");
    scanf("%d", &n);

    while (n != 0) {
        soma += n;
        printf("> ");
        scanf("%d", &n);
    }

    printf("total: %d\n", soma);
    return 0;
}
Nível 3

Exercício 1.06.3

Leia um número inteiro positivo e imprima quantos dígitos ele tem (ex.: 4528 tem 4 dígitos). Cuidado com o número 0.

Dica: Divida por 10 repetidamente até sobrar 0, contando as divisões.

Ver solução
#include <stdio.h>

int main(void)
{
    int n, qtd = 0;

    printf("Digite um numero: ");
    scanf("%d", &n);

    if (n == 0) {
        qtd = 1;
    } else {
        if (n < 0) {
            n = -n;
        }
        while (n > 0) {
            n = n / 10;
            qtd++;
        }
    }

    printf("digitos: %d\n", qtd);
    return 0;
}

O 0 é um caso especial: com 1 dígito, o while nem rodaria.

Nível 3

Exercício 1.06.4

Calcule e imprima uma aproximação do número de Euler e: some 1 + 1/1! + 1/2! + 1/3! + ... até o termo 1/n! ficar menor que 0.000001 (use um double para o fatorial).

Dica: Mantenha fat multiplicando por i a cada volta: fat = fat * i.

Ver solução
#include <stdio.h>

int main(void)
{
    double e = 1.0;
    double fat = 1.0;
    double termo;
    int i = 1;

    do {
        fat *= i;
        termo = 1.0 / fat;
        e += termo;
        i++;
    } while (termo >= 0.000001);

    printf("aproximacao de e: %.10f\n", e);
    return 0;
}

O do-while garante ao menos uma soma, e o laço para quando o termo fica pequeno demais.

Nível 3

Exercício 1.06.5

Print uma "escada digital" com dois loops aninhados: para cada linha i, imprima os números de 1 até i. Ex.: linha 3 imprime "1 2 3". Vá de 1 até 5.

Dica: O loop externo controla a linha; o interno os números dela.

Ver solução
#include <stdio.h>

int main(void)
{
    int i, j;

    for (i = 1; i <= 5; i++) {
        for (j = 1; j <= i; j++) {
            printf("%d ", j);
        }
        printf("\n");
    }
    return 0;
}

O laço interno usa a variável do externo (i) como limite — por isso as linhas crescem.

Nível 3

Exercício 1.06.6

Imprima todos os números primos de 2 a 100, um por linha, usando uma função de teste inline (flag + break) dentro do próprio loop externo.

Dica: Reuse a lógica do exemplo primo.c, mas agora ia percorrendo cada candidato.

Ver solução
#include <stdio.h>

int main(void)
{
    int n, i, eh_primo;

    for (n = 2; n <= 100; n++) {
        eh_primo = 1;
        for (i = 2; i * i <= n; i++) {
            if (n % i == 0) {
                eh_primo = 0;
                break;
            }
        }
        if (eh_primo) {
            printf("%d\n", n);
        }
    }
    return 0;
}

🏗️ Miniprojeto: Tabela de quadrados e cubos

Crie tabela.c: um programa que imprime uma tabela de n de 1 até N (N lido do teclado, máximo 100): colunas "n", "n^2", "n^3" e "soma acumulada" (dos n^2 até aquela linha). Use loops, largura fixa (%6d) e algumas formatações. Ao final, imprima o total geral dos quadrados.

Critérios de aceite

  • Lê N e valida (rejeita N > 100 ou N < 1 com loop do-while).
  • Imprime o cabeçalho e as linhas com colunas alinhadas.
  • Calcula a soma acumulada dos quadrados e o total geral.
  • Compila com -Wall -Wextra -std=c11 sem avisos.
