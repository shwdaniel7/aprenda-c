Variáveis, tipos e atribuição

Variáveis: caixas nomeadas com tipo

Uma variável é um espaço de memória que você dá um nome e um tipo. O tipo diz quantos bytes aquela "caixa" ocupa e como interpretar o conteúdo. Você manipula variáveis pelo nome; quem cuida de "onde na memória ela vive" é o compilador.

  • int — número inteiro (ex.: -42, 0, 1000).
  • char — um único caractere (ex.: 'A', '7', '¥').
  • float — número de ponto flutuante (ex.: 3.14f).
  • double — ponto flutuante com mais precisão (é o mais usado para "números reais").
  • Há ainda short, long, unsigned etc. — todos serão explorados a fundo no módulo 07.

Declarar, atribuir, inicializar

Declarar é criar a variável: tipo nome;. Atribuir é guardar um valor nela: nome = valor;. Inicializar é fazer os dois de uma vez: int idade = 25;. O programa abaixo mostra os quatro tipos básicos em ação:

Código — primeiro programa de tipos
#include <stdio.h>

int main(void)
{
    int idade = 25;
    char inicial = 'D';
    float altura = 1.75f;
    double precisao = 3.141592653589793;

    printf("idade: %d\n", idade);
    printf("inicial: %c\n", inicial);
    printf("altura: %.2f\n", altura);
    printf("precisao: %.12f\n", precisao);
    return 0;
}
Saída esperada
idade: 25
inicial: D
altura: 1.75
precisao: 3.141592653590

Regras para nomes (identificadores)

O nome de uma variável é um identificador, e obedece a regras rígidas:

  • Letras (a–z, A–Z), dígitos (0–9) e sublinhado _, mas o primeiro caractere não pode ser dígito.
  • Não pode ser uma palavra reservada (veja a próxima seção).
  • Maiúsculas e minúsculas são diferentes: Nota e nota são variáveis distintas.
  • Por convenção, variáveis em C usam letras minúsculas: mediaFinal ou media_final (escolha um estilo e seja consistente).
  • Nomes que começam com _ ou com __ são reservados ao sistema — evite.

Palavras reservadas e constante "não nomeada"

A linguagem reserva certo conjunto de palavras — você não pode usá-las como nome de variável:

  • auto break case char const continue default do double else enum extern float for goto if int long register return short signed sizeof static struct switch typedef union unsigned void volatile while
  • O padrão C11 ainda reserva palavras com sublinhado (_Bool, _Complex, _Static_assert...).
  • Uma constante literal é um valor escrito direto no código: 25, 3.14, 'A'. Ela não é uma variável.
  • Não confunda constantes com #define: #define MAX 100 é uma macro do pré-processador, um "troca-texto" que acontece antes de compilar — não é uma constante da linguagem. Ela é útil, mas é outra categoria (a veremos a fundo na Trilha 2).

Programa: média simples

Vamos calcular a média de duas notas. A divisão por 2.0 (com vírgula e zero) garante que a operação é de ponto flutuante — se dividíssemos por 2, com inteiros, o resultado seria truncado (assunto do módulo 04):

Código — media.c
#include <stdio.h>

int main(void)
{
    double nota1 = 7.5;
    double nota2 = 8.0;
    double media = (nota1 + nota2) / 2.0;

    printf("nota 1: %.1f\n", nota1);
    printf("nota 2: %.1f\n", nota2);
    printf("media: %.2f\n", media);
    return 0;
}
Saída esperada
nota 1: 7.5
nota 2: 8.0
media: 7.75

Programa: troca de valores

Trocar o conteúdo de duas variáveis é uma operação clássica. A intuição errada é fazer a = b; logo de cara — isso destruiria o valor original de a. A receita certa usa uma variável temporária:

Código — troca.c
#include <stdio.h>

int main(void)
{
    int a = 10;
    int b = 20;
    int temp;

    printf("antes: a=%d b=%d\n", a, b);

    temp = a;
    a = b;
    b = temp;

    printf("depois: a=%d b=%d\n", a, b);
    return 0;
}
Saída esperada
antes: a=10 b=20
depois: a=20 b=10

✏️ Exercícios

Nível 1

Exercício 1.02.1

Declare variáveis para sua idade (int), a letra inicial do seu nome (char), sua altura em metros (double) e imprima as três com printf.

Dica: Inicialize cada uma na declaração e use %d, %c e %.2f.

Ver solução
#include <stdio.h>

int main(void)
{
    int idade = 30;
    char inicial = 'M';
    double altura = 1.72;

    printf("idade: %d\n", idade);
    printf("inicial: %c\n", inicial);
    printf("altura: %.2f m\n", altura);
    return 0;
}
Nível 1

Exercício 1.02.2

Calcule a média de quatro notas (7.0, 8.5, 6.25, 9.0) guardadas em quatro variáveis double e imprima a média com duas casas decimais.

Dica: Lembre de dividir por 4.0, não por 4.

Ver solução
#include <stdio.h>

int main(void)
{
    double n1 = 7.0;
    double n2 = 8.5;
    double n3 = 6.25;
    double n4 = 9.0;
    double media = (n1 + n2 + n3 + n4) / 4.0;

    printf("media: %.2f\n", media);
    return 0;
}

7.0 + 8.5 + 6.25 + 9.0 = 30.75; 30.75 / 4 = 7.6875.

Nível 2

Exercício 1.02.3

Escreva um programa que troca os valores de x e y sem declarar variável temporária: use apenas somas e subtrações entre eles (x = x + y). Teste com x = 3, y = 5.

Dica: Depois de x = x + y, faça y = x - y e por fim x = x - y.

Ver solução
#include <stdio.h>

int main(void)
{
    int x = 3;
    int y = 5;

    printf("antes: x=%d y=%d\n", x, y);

    x = x + y;
    y = x - y;
    x = x - y;

    printf("depois: x=%d y=%d\n", x, y);
    return 0;
}

Funciona para inteiros, mas cuidado com overflow para valores muito grandes — a variável temporária é mais segura e legível.

Nível 2

Exercício 1.02.4

Um produto custa 120.00 e recebe 10% de desconto. Declare preço, percentual e desconto em double; calcule e imprima o valor do desconto e o preço final, ambos com duas casas.

Dica: desconto = preco * percentual / 100.0.

Ver solução
#include <stdio.h>

int main(void)
{
    double preco = 120.00;
    double percentual = 10.0;
    double desconto = preco * percentual / 100.0;
    double final = preco - desconto;

    printf("desconto: R$ %.2f\n", desconto);
    printf("preco final: R$ %.2f\n", final);
    return 0;
}

❓ Verificação rápida

🏗️ Miniprojeto: Crachá digital

Crie um programa cracha.c que representa "você" com variáveis dos quatro tipos básicos: a letra inicial do nome (char), a idade (int), a altura (double) e uma "nota de motivação" 0–10 (double). Imprima um crachá em várias linhas usando printf, com o nome do projeto centrado e cada dado em sua linha. Depois, troque os valores das variáveis para representar outra pessoa e mostre que o mesmo código "atualiza" o crachá.

Critérios de aceite

  • Declara as 4 variáveis com tipos corretos, inicializadas.
  • Imprime um crachá legível com os dados em linhas separadas.
  • A troca para a "segunda pessoa" usa novas atribuições às mesmas variáveis.
  • Compila com gcc -Wall -Wextra -std=c11 cracha.c -o cracha sem erros nem avisos.
