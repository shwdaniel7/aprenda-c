Aritmética: + - * / %

Os cinco operadores aritméticos do C são + - * / %. O último, %, é o resto da divisão inteira (também chamado de módulo): 7 % 3 vale 1, porque 7 dividido por 3 dá 2 com resto 1.

A divisão merece destaque: com dois inteiros, / faz divisão inteira e trunca o resultado (7 / 2 vale 3). Se pelo menos um dos operandos for de ponto flutuante, a divisão é real (7.0 / 2 vale 3.5).

Com números negativos, % em C acompanha o sinal do dividendo: -7 % 3 vale -1 e 7 % -3 vale 1.

Precedência e associatividade

A precedência decide quem opera primeiro quando a expressão mistura operadores (2 + 3 * 4 é 14, não 20). A associatividade decide a ordem entre operadores do mesmo nível (todos da esquerda para a direita no caso de * / % e + -).

  • () — parênteses: sempre primeiro, use sem medo.
  • ++ -- — incremento/decremento (pós/pré).
  • * / % — multiplicativos (esquerda → direita).
  • + - — aditivos (esquerda → direita).
  • < <= > >=, depois == != — relacionais (comparação).
  • &&, depois || — lógicos (vêm ainda nesta trilha).
  • Regra de ouro: quando houver dúvida, use parênteses — legibilidade conta mais que "saber de cor".

Atribuição composta

C permite atalhos para "mude a variável usando ela mesma": x += 5 é o mesmo que x = x + 5. Isso vale para += -= *= /= %=. É do jeito que o código "real" em C costuma ser escrito.

Código — operadores combinados
#include <stdio.h>

int main(void)
{
    int saldo = 500;

    saldo += 150;
    printf("apos deposito: %d\n", saldo);

    saldo -= 80;
    printf("apos saque: %d\n", saldo);

    saldo *= 2;
    printf("apos dobrar: %d\n", saldo);

    saldo /= 3;
    printf("apos dividir: %d\n", saldo);

    saldo %= 100;
    printf("resto por 100: %d\n", saldo);
    return 0;
}
Saída esperada
apos deposito: 650
apos saque: 570
apos dobrar: 1140
apos dividir: 380
resto por 100: 80

Incremento e decremento: ++ e --

x++ soma 1 a x; x-- subtrai 1. A diferença entre pré e pós aparece quando o operador está no meio de uma expressão: no pós (x++) a expressão usa o valor antigo; no pré (++x) usa o valor novo.

Atenção (regra de ouro): não misture incremento com outras operações na mesma expressão — b = a++ + a gera resultado indefinido em C. Use ++/-- como instrução isolada, ou dentro de for (módulo 06), e pronto.

Relacionais e lógicos: verdade como número

Operadores relacionais — == != < <= > >= — retornam 1 (verdadeiro) ou 0 (falso). C não tem tipo booleano obrigatório: qualquer valor diferente de zero é "verdadeiro", e o zero é "falso".

Os lógicos && (e), || (ou) e ! (não) seguem a mesma lógica, e ainda têm um comportamento especial de curto-circuito: no &&, se a primeira parte for falsa, a segunda nem é avaliada; no ||, se a primeira for verdadeira, a segunda é pulada. Isso será útil (e perigoso) adiante.

Código — lógica
#include <stdio.h>

int main(void)
{
    int x = 5;

    printf("x > 3 (1 para sim): %d\n", x > 3);
    printf("(x > 3) && (x < 10): %d\n", x > 3 && x < 10);
    printf("(x < 3) || (x == 5): %d\n", x < 3 || x == 5);
    printf("!(x > 3): %d\n", !(x > 3));
    return 0;
}
Saída esperada
x > 3 (1 para sim): 1
(x > 3) && (x < 10): 1
(x < 3) || (x == 5): 1
!(x > 3): 0

Programa: segundos em horas, minutos e segundos

Um uso clássico de / e %: decompor um total de segundos em horas, minutos e segundos.

Código — segundos.c
#include <stdio.h>

int main(void)
{
    int total = 7543;
    int horas, minutos, segundos;

    horas = total / 3600;
    minutos = (total % 3600) / 60;
    segundos = total % 60;

    printf("%d segundos = %dh %dm %ds\n", total, horas, minutos, segundos);
    return 0;
}
Saída esperada
7543 segundos = 2h 5m 43s

Programa: juros compostos passo a passo

Aqui as atribuições compostas trabalham juntas: a cada ano o montante recebe mais 10% dele mesmo.

Código — juros.c
#include <stdio.h>

int main(void)
{
    double montante = 1000.0;
    double taxa = 10.0;   /* % ao ano */
    int anos = 3;

    montante += montante * taxa / 100.0;  /* ano 1 */
    montante += montante * taxa / 100.0;  /* ano 2 */
    montante += montante * taxa / 100.0;  /* ano 3 */

    printf("apos %d anos: R$ %.2f\n", anos, montante);
    return 0;
}
Saída esperada
apos 3 anos: R$ 1331.00

✏️ Exercícios

Nível 2

Exercício 1.04.1

Leia um número inteiro de três algarismos (ex.: 287) e imprima os algarismos da unidade, dezena e centena separadamente.

Dica: unidade = n % 10; dezena = (n / 10) % 10; centena = n / 100.

Ver solução
#include <stdio.h>

int main(void)
{
    int n, u, d, c;

    printf("Digite um numero de 3 algarismos: ");
    scanf("%d", &n);

    u = n % 10;
    d = (n / 10) % 10;
    c = n / 100;

    printf("unidade: %d\n", u);
    printf("dezena: %d\n", d);
    printf("centena: %d\n", c);
    return 0;
}

Para 287: unidade 7, dezena 8, centena 2.

Nível 2

Exercício 1.04.2

Leia dois inteiros e imprima o quociente e o resto da divisão inteira, além do resultado da divisão real usando uma conversão.

Dica: Para a divisão real, escreva (double) a / b.

Ver solução
#include <stdio.h>

int main(void)
{
    int a, b;

    printf("Digite dois inteiros: ");
    scanf("%d %d", &a, &b);

    printf("%d / %d = %d (quociente)\n", a, b, a / b);
    printf("%d %% %d = %d (resto)\n", a, b, a % b);
    printf("%d / %d = %.2f (divisao real)\n", a, b, (double) a / b);
    return 0;
}

Repare no %% para imprimir um símbolo de porcentagem na frente.

Nível 2

Exercício 1.04.3

Sem rodar, calcule no papel o valor de x após int x = 3; x *= 2; x += 4; x -= x % 5;. Depois confirme com um programa.

Dica: x % 5 avalia com o x daquele momento. Use o programa para conferir cada passo.

Ver solução
#include <stdio.h>

int main(void)
{
    int x = 3;

    x *= 2;
    printf("passo 1: %d\n", x);
    x += 4;
    printf("passo 2: %d\n", x);
    x -= x % 5;
    printf("passo 3: %d\n", x);
    return 0;
}

Passos: 6, depois 10, depois 10 - (10 % 5) = 10 - 0 = 10. Atenção: o módulo usa o valor atual de x.

Nível 3

Exercício 1.04.4

Leia duas notas (double) e imprima a média ponderada com pesos 2 e 3 — mas desta vez declare uma variável peso1 e peso2 e escreva a conta com parênteses em toda parte, mesmo onde não precisa.

Dica: Use (n1 * peso1 + n2 * peso2) / (peso1 + peso2).

Ver solução
#include <stdio.h>

int main(void)
{
    double n1 = 6.5;
    double n2 = 8.0;
    double peso1 = 2.0;
    double peso2 = 3.0;
    double media = (n1 * peso1 + n2 * peso2) / (peso1 + peso2);

    printf("media ponderada: %.2f\n", media);
    return 0;
}
Nível 3

Exercício 1.04.5

Escreva um programa que demonstra o curto-circuito: faça uma condição (0 && funcaoPegaLado()) onde a função segunda teria um efeito (imprime um "aviso"), e mostre que com o && o aviso NÃO é impresso. Depois troque para || e veja o aviso.

Dica: funcao que imprime e retorna 1: o retorno precisa existir para a expressão compilar.

Ver solução
#include <stdio.h>

int aviso(void)
{
    printf("  [efeito colateral executado]\n");
    return 1;
}

int main(void)
{
    int a = 0;

    printf("Caso 1: (0 && aviso())\n");
    if (a && aviso()) {
        printf("  entrou no if\n");
    }

    printf("Caso 2: a || aviso()\n");
    if (a || aviso()) {
        printf("  entrou no if\n");
    }
    return 0;
}

No caso 1, o && é o primeiro operando falso, então aviso() nem roda. No caso 2, o || tem o primeiro operando falso, então aviso() roda para decidir.

❓ Verificação rápida

🏗️ Miniprojeto: Um "relógio" que avança minutos

Crie relogio.c: leia uma hora no formato "HH MM" (ex.: 23 58) e a quantidade de minutos a avançar; calcule a nova hora corretamente (incluindo a virada de 23:59 para 00:00). Use /, %, += e variáveis intermediárias. Imprima a hora de saída no formato HH:MM com largura fixa (%02d).

Critérios de aceite

  • Lê hora, minuto e avanço com scanf.
  • Trata a virada do dia: saídas como 23:58 + 5 = 00:03.
  • Usa pelo menos um = / % e uma atribuição composta.
  • Imprime com %02d:%02d e compila sem avisos.
