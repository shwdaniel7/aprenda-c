if e else: dois caminhos

O if decide se um bloco roda com base em uma condição. A regra de "verdade" em C é simples: a condição é falsa se a expressão vale 0, e verdadeira para qualquer outro valor. O else pega o caso contrário.

Código — primeiro if
#include <stdio.h>

int main(void)
{
    int n;

    printf("Digite um numero: ");
    scanf("%d", &n);

    if (n % 2 == 0) {
        printf("%d e par\n", n);
    } else {
        printf("%d e impar\n", n);
    }
    return 0;
}
Saída esperada
Digite um numero: 7
7 e impar

else if: mais de dois caminhos

Quando as opções são várias, encadeie else if. Cada condição só é testada se todas as anteriores falharem. A última avaliação (a que não tem condição) é o "senão" final.

Código — cadeia de decisões
#include <stdio.h>

int main(void)
{
    double nota;

    printf("Nota (0 a 10): ");
    scanf("%lf", &nota);

    if (nota >= 9.0) {
        printf("conceito A\n");
    } else if (nota >= 7.0) {
        printf("conceito B\n");
    } else if (nota >= 5.0) {
        printf("conceito C\n");
    } else {
        printf("reprovado\n");
    }
    return 0;
}
Saída esperada
Nota (0 a 10): 8.5
conceito B

Verdade em C: qualquer coisa diferente de zero

Como a verdade é "não-zero", o C aceita atalhos que em outras linguagens dão erro. if (x) é o mesmo que if (x != 0); if (!x) é o mesmo que if (x == 0). Graças ao curto-circuito, dá até para escrever if (n > 0 && n % 2 == 0) e ter "n positivo e par" numa condição só.

Cuidado: o atalho if (x) é o que leva o iniciante a escrever if (x = 5) em vez de if (x == 5) — a atribuição vale 5, que é "verdadeiro", e o bug passa despercebido (módulo 1.11 ataca isso a fundo).

O "dangling else"

Quando um if está dentro de outro e só há um else, a quem ele pertence? O C responde: o else se associa ao if mais próximo ainda sem par. O programa abaixo parece "óbvio", mas o else pertence ao if interno:

Código — else perdido
#include <stdio.h>

int main(void)
{
    int x = 1;
    int y = 1;

    if (x > 1)
        /* BUG: sem chaves, o else fica ambiguo */
        if (y > 1)
            printf("os dois sao grandes\n");
        /* este else pertence ao if de cima! */
        else
            printf("entrei: x > 1, mas y nao\n");

    printf("fim do programa\n");
    return 0;
}
Saída esperada
dangling.c:8:8: warning: suggest explicit braces to avoid ambiguous 'else' [-Wdangling-else]
    8 |     if (x > 1)
      |        ^

fim do programa

switch: quando comparar com muitos valores

O switch compara uma expressão inteira (ou char) com uma série de case. Cada case deve terminar com break, senão ocorre o fall-through — a execução "vaza" para o próximo caso. O default é opcional e pega nada que nenhum caso cubra.

Código — switch
#include <stdio.h>

int main(void)
{
    int mes;

    printf("Numero do mes (1-12): ");
    scanf("%d", &mes);

    switch (mes) {
        case 1:
        case 3:
        case 5:
        case 7:
        case 8:
        case 10:
        case 12:
            printf("31 dias\n");
            break;
        case 4:
        case 6:
        case 9:
        case 11:
            printf("30 dias\n");
            break;
        case 2:
            printf("28 ou 29 dias (fevereiro)\n");
            break;
        default:
            printf("mes invalido\n");
            break;
    }
    return 0;
}
Saída esperada
Numero do mes (1-12): 6
30 dias

O operador ternário ?:

Para "if que escolhe um valor", existe o operador ternário: cond ? valorSe : valorNao. Ele é ótimo como abreviação, e péssimo quando vira "coding golf". Use para escolhas curtas.

Código — ternário
#include <stdio.h>

int main(void)
{
    int idade = 17;
    char *status = idade >= 18 ? "maior de idade" : "menor de idade";

    printf("%d anos: %s\n", idade, status);
    return 0;
}
Saída esperada
17 anos: menor de idade

✏️ Exercícios

Nível 2

Exercício 1.05.1

Leia um número inteiro e diga se ele é positivo, negativo ou zero.

Dica: Três caminhos: if (n > 0), else if (n < 0), else.

Ver solução
#include <stdio.h>

int main(void)
{
    int n;

    printf("Digite um numero: ");
    scanf("%d", &n);

    if (n > 0) {
        printf("positivo\n");
    } else if (n < 0) {
        printf("negativo\n");
    } else {
        printf("zero\n");
    }
    return 0;
}
Nível 2

Exercício 1.05.2

Leia três números inteiros e imprima o maior deles (use a técnica do "maior até agora": comece com o primeiro e vá atualizando).

Dica: Não precisa de &&: atualize o maior na hora com dois ifs simples.

Ver solução
#include <stdio.h>

int main(void)
{
    int a, b, c, maior;

    printf("Digite tres numeros: ");
    scanf("%d %d %d", &a, &b, &c);

    maior = a;
    if (b > maior) {
        maior = b;
    }
    if (c > maior) {
        maior = c;
    }

    printf("maior: %d\n", maior);
    return 0;
}
Nível 2

Exercício 1.05.3

Leia altura (m) e peso (kg) e classifique o IMC: abaixo de 18.5 "abaixo", de 18.5 a 24.9 "normal", de 25 a 29.9 "sobrepeso" e 30+ "obesidade". IMC = peso / altura².

Dica: altura² = altura * altura. Teste os limites em cada faixa com >=.

Ver solução
#include <stdio.h>

int main(void)
{
    double altura, peso, imc;

    printf("Peso (kg): ");
    scanf("%lf", &peso);
    printf("Altura (m): ");
    scanf("%lf", &altura);

    imc = peso / (altura * altura);

    printf("IMC: %.2f -> ", imc);
    if (imc < 18.5) {
        printf("abaixo do peso\n");
    } else if (imc < 25.0) {
        printf("peso normal\n");
    } else if (imc < 30.0) {
        printf("sobrepeso\n");
    } else {
        printf("obesidade\n");
    }
    return 0;
}
Nível 3

Exercício 1.05.4

Use switch para imprimir o nome do dia da semana a partir de um número 1–7 (1 = domingo ... 7 = sábado). Se o número for inválido, imprima "dia invalido".

Dica: Cada case com seu break; o default lida com o resto.

Ver solução
#include <stdio.h>

int main(void)
{
    int dia;

    printf("Dia da semana (1-7): ");
    scanf("%d", &dia);

    switch (dia) {
        case 1: printf("domingo\n"); break;
        case 2: printf("segunda\n"); break;
        case 3: printf("terca\n"); break;
        case 4: printf("quarta\n"); break;
        case 5: printf("quinta\n"); break;
        case 6: printf("sexta\n"); break;
        case 7: printf("sabado\n"); break;
        default: printf("dia invalido\n"); break;
    }
    return 0;
}
Nível 3

Exercício 1.05.5

Leia um ano e diga se é bissexto: divisível por 4, exceto os divisíveis por 100 (mas os divisíveis por 400 são bissextos). Combine as regras com && e ||.

Dica: Regra completa: (ano % 4 == 0 && ano % 100 != 0) || ano % 400 == 0.

Ver solução
#include <stdio.h>

int main(void)
{
    int ano;

    printf("Ano: ");
    scanf("%d", &ano);

    if ((ano % 4 == 0 && ano % 100 != 0) || ano % 400 == 0) {
        printf("%d e bissexto\n", ano);
    } else {
        printf("%d nao e bissexto\n", ano);
    }
    return 0;
}

1900 não é bissexto (÷100 mas não ÷400); 2000 é (÷400).

🏗️ Miniprojeto: Calculadora de IMC completa

Melhore o classificador de IMC: leia peso e altura, calcule o IMC com 2 casas e, além de classificar em 4 faixas (abaixo/normal/sobrepeso/obesidade), informe o peso ideal aproximado para uma altura "normal" (IMC 22) e uma dica simples (aumentar ou reduzir peso) em função da faixa. Use if/else if e pelo menos um switch ou ternário em algum ponto.

Critérios de aceite

  • Lê peso e altura como double.
  • Classifica em pelo menos 4 faixas de IMC com mensagens diferentes.
  • Calcula o peso que daria IMC 22 para a altura informada.
  • Trata entrada inválida (peso ou altura ≤ 0).
  • Compila com -Wall -Wextra -std=c11 sem avisos.
