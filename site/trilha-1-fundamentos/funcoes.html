Por que funções?

Uma função é uma unidade de código com nome, que recebe parâmetros (opcionais), faz algo e retorna um valor (ou nada, com void). Funções dão nome às partes do programa, eliminam duplicação e isolam erros. Um programa bem dividido em funções pequenas é lido quase como prosa.

Peça por peça de uma definição: retorno nome(parametros) { corpo }.

Anatomia: retorno, parâmetros, corpo

No exemplo, media recebe duas notas e devolve a média. Repare que o return envia o valor para quem chamou, e que chamar a função dentro de um printf é comum.

Código — definindo
#include <stdio.h>

double media(double n1, double n2)
{
    return (n1 + n2) / 2.0;
}

int main(void)
{
    printf("media de 7.5 e 8.5: %.2f\n", media(7.5, 8.5));
    printf("media de 10.0 e 2.0: %.2f\n", media(10.0, 2.0));
    return 0;
}
Saída esperada
media de 7.5 e 8.5: 8.00
media de 10.0 e 2.0: 6.00

Protótipos: declare antes de usar

O compilador lê o arquivo de cima para baixo. Se main aparece antes da função que ela chama, o gcc reclamará ("implicit declaration") — um warning. A solução é colocar um protótipo (só o cabeçalho + ;) antes do main. É o profissional: todo cabeçalho costuma vir no topo.

Código — protótipos
#include <stdio.h>

int eh_par(int n);   /* protótipo: declara a função antes do uso */

int main(void)
{
    int x = 8;

    if (eh_par(x)) {
        printf("%d e par\n", x);
    } else {
        printf("%d e impar\n", x);
    }
    return 0;
}

int eh_par(int n)
{
    return n % 2 == 0;
}
Saída esperada
8 e par

Passagem por valor: a cópia que não volta

Em C, os parâmetros são cópias: a função recebe o valor, não a variável. Mexer no parâmetro não altera a variável do chamador. Por isso a "troca" abaixo não troca nada — e por isso precisamos de ponteiros (Trilha 2) para funções que modificam o chamador.

Código — passagem por valor
#include <stdio.h>

void tenta_trocar(int a, int b)
{
    int temp = a;
    a = b;
    b = temp;
}

int main(void)
{
    int x = 1;
    int y = 2;

    printf("antes da chamada: x=%d y=%d\n", x, y);
    tenta_trocar(x, y);
    printf("depois da chamada: x=%d y=%d\n", x, y);
    return 0;
}
Saída esperada
antes da chamada: x=1 y=2
depois da chamada: x=1 y=2

main(void) vs main()

int main(void) declara que main não recebe argumentos. int main() é a sintaxe "antiga", que em C de verdade significa "recebe o que vier" (sem protótipo). O padrão recomenda int main(void) — e é o que usamos em todo o curso. (Quando quisermos ler argumentos do terminal, será int main(int argc, char *argv[]), no módulo 1.12.)

Recursão: a função que chama a si mesma (degustação)

Uma função pode chamar a si mesma: isso é recursão. Ela precisa de um caso base que para a cadeia e um passo recursivo que se aproxima dele. O fatorial é o exemplo clássico: n! = n × (n-1)!, com 0! = 1. Recursão a fundo (quando usar, quando evitar, pilha) é assunto da Trilha 2 — aqui é degustação.

Código — recursão
#include <stdio.h>

long long fatorial(int n)
{
    if (n <= 1) {
        return 1;
    }
    return n * fatorial(n - 1);
}

int main(void)
{
    int n;

    printf("Fatorial de qual numero? ");
    scanf("%d", &n);

    printf("%d! = %lld\n", n, fatorial(n));
    return 0;
}
Saída esperada
Fatorial de qual numero? 10
10! = 3628800

Programa: teste de primalidade como função

Fechando com o eh_primo reescrito como função: a função devolve 1 (verdadeiro) ou 0 (falso), e o main fica pequeno, contando a história.

Código — primo-função
#include <stdio.h>

int eh_primo(int n)
{
    int i;

    if (n < 2) {
        return 0;
    }
    for (i = 2; i * i <= n; i++) {
        if (n % i == 0) {
            return 0;
        }
    }
    return 1;
}

int main(void)
{
    int n;

    printf("Digite um numero: ");
    scanf("%d", &n);

    if (eh_primo(n)) {
        printf("%d e primo\n", n);
    } else {
        printf("%d nao e primo\n", n);
    }
    return 0;
}
Saída esperada
Digite um numero: 29
29 e primo

Nível 2

Exercício 1.09.1

Escreva uma função potencia(int base, int exp) que calcula base^exp com um loop (exp >= 0) e a chame no main para 2^10, 3^4 e 5^0.

Dica: Acumule o resultado multiplicando pela base, exp vezes.

Ver solução
#include <stdio.h>

int potencia(int base, int exp)
{
    int i;
    int resultado = 1;

    for (i = 0; i < exp; i++) {
        resultado *= base;
    }
    return resultado;
}

int main(void)
{
    printf("2^10 = %d\n", potencia(2, 10));
    printf("3^4  = %d\n", potencia(3, 4));
    printf("5^0  = %d\n", potencia(5, 0));
    return 0;
}
Nível 2

Exercício 1.09.2

Escreva uma função max3(int a, int b, int c) que devolve o maior dos três, e um main que lê três números e imprime o resultado.

Dica: Use a técnica "maior até agora" dentro da função.

Ver solução
#include <stdio.h>

int max3(int a, int b, int c)
{
    int maior = a;

    if (b > maior) {
        maior = b;
    }
    if (c > maior) {
        maior = c;
    }
    return maior;
}

int main(void)
{
    int x, y, z;

    printf("Digite tres numeros: ");
    scanf("%d %d %d", &x, &y, &z);

    printf("maior: %d\n", max3(x, y, z));
    return 0;
}
Nível 3

Exercício 1.09.3

Implemente a soma de 1 a n de forma RECURSIVA (somar de n até 1). Imprima o resultado para n = 100.

Dica: Caso base: se <= 1, devolve 1; senão, n + soma(n-1).

Ver solução
#include <stdio.h>

int soma_ate(int n)
{
    if (n <= 1) {
        return 1;
    }
    return n + soma_ate(n - 1);
}

int main(void)
{
    printf("soma de 1 a 100: %d\n", soma_ate(100));
    return 0;
}

Recursão a fundo fica para a Trilha 2; aqui é apenas o "gosto" do conceito.

Nível 3

Exercício 1.09.4

Escreva uma função fib(int n) ITERATIVA que devolve o n-ésimo termo de Fibonacci (1, 1, 2, 3, 5, 8...) e imprima fibonacci de 1 a 10.

Dica: Guarde um "atual" e um "anterior", atualizando em cada volta.

Ver solução
#include <stdio.h>

int fib(int n)
{
    int a = 1, b = 1, i, prox;

    for (i = 3; i <= n; i++) {
        prox = a + b;
        a = b;
        b = prox;
    }
    return b;
}

int main(void)
{
    int i;

    for (i = 1; i <= 10; i++) {
        printf("fib(%d) = %d\n", i, fib(i));
    }
    return 0;
}
Nível 3

Exercício 1.09.5

Crie uma função eh_digito_par(int n) que devolve 1 se TODOS os dígitos de n forem pares (0, 2, 4, 6, 8), e 0 caso contrário. Teste com 2468 (1) e 123 (0).

Dica: Vá "arrancando" dígitos com % e /, retornando 0 ao achar um ímpar.

Ver solução
#include <stdio.h>

int eh_digito_par(int n)
{
    if (n < 0) {
        n = -n;
    }
    if (n == 0) {
        return 1;   /* 0 e par */
    }

    while (n > 0) {
        if ((n % 10) % 2 != 0) {
            return 0;
        }
        n = n / 10;
    }
    return 1;
}

int main(void)
{
    printf("2468: %d\n", eh_digito_par(2468));
    printf("123: %d\n", eh_digito_par(123));
    printf("0: %d\n", eh_digito_par(0));
    return 0;
}
