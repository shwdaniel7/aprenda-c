argc, argv, atoi e um utilitário completo

argc e argv: o terminal falando com seu programa

Chamar .\meuprog.exe bom dia dá argc = 3. O argv[0] é o próprio nome do programa, argv[1] é o primeiro argumento ("bom") e argv[2] o segundo ("dia").

Detalhe do Windows: com o MinGW, o argv[0] costuma chegar com o caminho completo (ex.: C:\minha\pasta\eco.exe), enquanto no Linux costuma ser só o nome digitado. Isso não muda nada no que você programa — mas explica por que a primeira linha do exemplo abaixo varia de máquina para máquina.

Código — argc argv
#include <stdio.h>

int main(int argc, char *argv[])
{
    int i;

    printf("argc: %d\n", argc);
    for (i = 0; i < argc; i++) {
        printf("argv[%d]: %s\n", i, argv[i]);
    }
    return 0;
}
Saída esperada
> .\eco.exe bom dia ja
argc: 4
argv[0]: C:\caminho\para\eco.exe
argv[1]: bom
argv[2]: dia
argv[3]: ja

Convertendo texto em número: atoi

Argumentos chegam como texto; para somar, precisamos converter. A função atoi (ASCII-to-integer, de <stdlib.h>) faz exatamente isso: lê os dígitos e devolve o int. O utilitário abaixo valida o número de argumentos e imprime a soma:

Código — atoi
#include <stdio.h>
#include <stdlib.h>

int main(int argc, char *argv[])
{
    int a, b;

    if (argc != 3) {
        printf("uso: soma.exe numero1 numero2\n");
        return 1;
    }

    a = atoi(argv[1]);
    b = atoi(argv[2]);

    printf("%d + %d = %d\n", a, b, a + b);
    return 0;
}
Saída esperada
> .soma.exe 4 9
4 + 9 = 13

> .soma.exe sem_arg
uso: soma.exe numero1 numero2

O fluxo de um utilitário: entrada → processamento → saída

Um programa de terminal bem-feito obedece um esqueleto previsível:

  • Entrada — argumentos (argc/argv) e/ou leitura de teclado (scanf).
  • Validação — quantidade de argumentos, tipos, limites. Falhou? mensagem de uso e return 1 (código de erro).
  • Processamento — as contas, loops, funções (o "miolo").
  • Saída — resultado formatado; return 0 para sucesso.

Dividir para conquistar: main fino

Um bom utilitário tem main pequeno e funções específicas para cada passo. Onde está a lógica? Nas funções, testáveis e legíveis. É o "cheiro" de programa profissional: você lê o main e sabe o que o programa faz em 5 linhas.

Código — main fino
#include <stdio.h>
#include <stdlib.h>

double media_de_n(int n)
{
    long long soma = 0;
    int i;

    for (i = 1; i <= n; i++) {
        soma += i;
    }
    return soma / (double) n;
}

int main(int argc, char *argv[])
{
    int n;

    if (argc != 2) {
        printf("uso: media.exe N\n");
        return 1;
    }
    n = atoi(argv[1]);

    if (n <= 0) {
        printf("erro: N deve ser positivo\n");
        return 1;
    }

    printf("media dos numeros de 1 a %d: %.4f\n", n, media_de_n(n));
    return 0;
}
Saída esperada
> .media.exe 10
media dos numeros de 1 a 10: 5.5000

Exemplo completo: um interpretador de comandos

O projeto final (abaixo) é um interpretador de comandos: um loop que lê um comando ("s" soma, "m" média, "?" ajuda, "q" sair), executa e repete. É um "mini shell" numérico — joga com for (;;), switch, scanf e funções: tudo desta trilha em um único programa. A versão de referência:

Código — interpretador
#include <stdio.h>

void menu(void)
{
    printf("Comandos:\n");
    printf("  s <n1> <n2>   soma dois numeros\n");
    printf("  m             media de 3 numeros\n");
    printf("  ?             mostra este menu\n");
    printf("  q             sai\n");
}

double soma(double a, double b)
{
    return a + b;
}

double media3(double a, double b, double c)
{
    return (a + b + c) / 3.0;
}

int main(void)
{
    char comando;
    double a, b, c;

    menu();

    for (;;) {
        printf("> ");
        scanf(" %c", &comando);

        if (comando == 'q') {
            printf("Ate mais!\n");
            break;
        } else if (comando == 's') {
            scanf("%lf %lf", &a, &b);
            printf("%.2f + %.2f = %.2f\n", a, b, soma(a, b));
        } else if (comando == 'm') {
            scanf("%lf %lf %lf", &a, &b, &c);
            printf("media: %.2f\n", media3(a, b, c));
        } else if (comando == '?') {
            menu();
        } else {
            printf("comando invalido. use ? para ajuda.\n");
        }
    }
    return 0;
}
Saída esperada
Comandos:
  s <n1> <n2>   soma dois numeros
  m             media de 3 numeros
  ?             mostra este menu
  q             sai
> ?
Comandos:
  s <n1> <n2>   soma dois numeros
  m             media de 3 numeros
  ?             mostra este menu
  q             sai
> s 2.5 3
2.50 + 3.00 = 5.50
> m 10 20 30
media: 20.00
> q

Como testar seu programa

Teste de terminal é previsível: monte uma lista de casos e execute todos.

  • Nenhum argumento (mensagem de uso).
  • Argumentos inválidos (texto em vez de número) — atoi devolve 0; decida o comportamento.
  • Casos-limite: 0, negativos, valores que podem estourar long long.
  • Entrada incompleta no interpretador ("s" sem números) — o scanf espera e o programa pausa.
  • Sempre compile com -Wall -Wextra — um utilitário com warning é um utilitário com dívida.

O projeto final: passo a passo

Seguindo a receita abaixo, você constrói o calc_estudo.exe (detalhes no quadro do projeto):

  • Esqueleto: crie calc_estudo.c com menu() e main que chama menu() e entra no for (;;).
  • Comando soma: adicione s com leitura de dois doubles e a função soma(). Compile, teste.
  • Comando media: m com três doubles e media3(). Compile, teste.
  • Comando extra: escolha p (produto), d (desconto) ou f (fatorial). Compile, teste.
  • Histórico: com static, guarde quantas operações foram feitas e exiba com h.
  • Polimento: mensagem de uso, validações, e rodada final com -Wall -Wextra em todos os testes.

✏️ Exercícios

Nível 2

Exercício 1.12.1

Crie um programa eco.c que imprime todos os argumentos (a partir de argv[1]) separados por espaço em uma única linha, ignorando argv[0].

Dica: Um for de i=1 até argc-1 com printf("%s ", argv[i]).

Ver solução
#include <stdio.h>

int main(int argc, char *argv[])
{
    int i;

    for (i = 1; i < argc; i++) {
        printf("%s ", argv[i]);
    }
    printf("\n");
    return 0;
}

Rode: .\eco.exe bom dia → bom dia.

Nível 2

Exercício 1.12.2

Crie mult.exe: leia DOIS argumentos, converta com atoi e imprima o produto. Se não houver exatamente dois argumentos, imprima a mensagem de uso e retorne 1.

Dica: Validar argc antes de converter evita crash com argumentos faltando.

Ver solução
#include <stdio.h>
#include <stdlib.h>

int main(int argc, char *argv[])
{
    int a, b;

    if (argc != 3) {
        printf("uso: mult.exe numero1 numero2\n");
        return 1;
    }

    a = atoi(argv[1]);
    b = atoi(argv[2]);

    printf("%d * %d = %d\n", a, b, a * b);
    return 0;
}
Nível 3

Exercício 1.12.3

Crie media_args.exe: aceita quantos argumentos numéricos o usuário quiser, converte todos com atoi, soma e imprime a média com 2 casas. Se não houver argumentos, mensagem de uso.

Dica: argc - 1 é a quantidade de números; some cada argv[i] convertido.

Ver solução
#include <stdio.h>
#include <stdlib.h>

int main(int argc, char *argv[])
{
    int i;
    long long soma = 0;

    if (argc < 2) {
        printf("uso: media_args.exe n1 n2 n3 ...\n");
        return 1;
    }

    for (i = 1; i < argc; i++) {
        soma += atoi(argv[i]);
    }

    printf("media: %.2f\n", soma / (double) (argc - 1));
    return 0;
}

A média usa (argc - 1) como divisor — a quantidade de números lidos.

Nível 3

Exercício 1.12.4

Refatore o soma.exe (o exemplo de atoi) em três funções: uso() (imprime e sai), somar(int a, int b) e um main que só valida e chama. O programa continua idêntico em comportamento.

Dica: uso() pode imprimir e retornar um código; main usa o retorno no return.

Ver solução
#include <stdio.h>
#include <stdlib.h>

int uso(void)
{
    printf("uso: soma.exe numero1 numero2\n");
    return 1;
}

int somar(int a, int b)
{
    return a + b;
}

int main(int argc, char *argv[])
{
    int a, b;

    if (argc != 3) {
        return uso();
    }

    a = atoi(argv[1]);
    b = atoi(argv[2]);

    printf("%d + %d = %d\n", a, b, somar(a, b));
    return 0;
}
Nível 3

Exercício 1.12.5

Crie converte.exe que recebe um argumento numérico e o converte de Celsius para Fahrenheit, e outro que faz o caminho inverso — decida pela presença de um segundo argumento ("c" ou "f"). Ex.: converte.exe 37 c converte 37°C para °F.

Dica: Um if no argv[2] escolhe a fórmula; a fórmula de F→C é (F−32)×5/9.

Ver solução
#include <stdio.h>
#include <stdlib.h>

int main(int argc, char *argv[])
{
    double valor;

    if (argc != 3) {
        printf("uso: converte.exe <valor> <c|f>\n");
        printf("  c: Celsius -> Fahrenheit\n");
        printf("  f: Fahrenheit -> Celsius\n");
        return 1;
    }

    valor = atof(argv[1]);

    if (argv[2][0] == 'c') {
        printf("%.2f C = %.2f F\n", valor, valor * 9.0 / 5.0 + 32.0);
    } else if (argv[2][0] == 'f') {
        printf("%.2f F = %.2f C\n", valor, (valor - 32.0) * 5.0 / 9.0);
    } else {
        printf("erro: segundo argumento deve ser c ou f\n");
        return 1;
    }
    return 0;
}

atof converte texto para double (como atoi, mas para ponto flutuante).

🏗️ Miniprojeto: CalcEstudo: seu interpretador de comandos

Construa calc_estudo.exe, um interpretador de comandos numéricos que rode em loop: comandos s (soma de 2 números), m (média de 3), f (fatorial de um número via função recursiva ou iterativa), h (mostra quantas operações foram executadas até agora, usando variável estática), ? (menu) e q (sai). Siga o passo a passo da seção "projeto final", compilando e testando a cada comando adicionado. Baseie-se no interpretador de referência da seção e estenda-o com o comando f e o histórico h.

Critérios de aceite

  • Roda em loop até o comando q, com o menu ?.
  • Implementa soma (s), média (m), fatorial (f) e histórico (h) com funções próprias.
  • Histórico usa variável estática (estado interno sem global).
  • Valida entradas: fatorial de 0 ou 1 = 1; valores negativos rejeitados.
  • Compila com gcc -Wall -Wextra -std=c11 calc_estudo.c -o calc_estudo sem erros nem avisos.
  • Você consegue explicar, para outra pessoa, cada função do seu programa
