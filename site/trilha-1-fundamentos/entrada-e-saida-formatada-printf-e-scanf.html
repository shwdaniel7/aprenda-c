Entrada e saída formatada: printf e scanf

conversões, largura, precisão e leitura do teclado

Nível: Iniciante Duração: ~45 min Pré-requisitos: T1.02

printf: o conversor de valores em texto

O printf recebe um texto com "buracos" chamados de especificadores de conversão e, depois, os valores que preenchem esses buracos. Cada especificador começa com % e termina com uma letra que diz o tipo:

  • %d — inteiro decimal (int).
  • %x — inteiro em hexadecimal (%X em maiúsculas).
  • %f — ponto flutuante (double/float).
  • %c — um caractere (char).
  • %s — uma sequência de caracteres (texto).
  • %% — imprime um % literal (para não abrir um novo buraco).
Código — conversões
#include <stdio.h>

int main(void)
{
    int n = 255;
    double pi = 3.14159;
    char letra = 'Z';

    printf("inteiro: %d\n", n);
    printf("hexadecimal: %x\n", n);
    printf("real: %f\n", pi);
    printf("real com 2 casas: %.2f\n", pi);
    printf("um char: %c\n", letra);
    printf("uma frase: %s\n", "Aprenda C");
    printf("porcentagem: %%\n");
    return 0;
}
Saída esperada
inteiro: 255
hexadecimal: ff
real: 3.141590
real com 2 casas: 3.14
um char: Z
uma frase: Aprenda C
porcentagem: %

Largura, precisão e alinhamento

Você pode controlar todo o visual: a largura mínima do campo, as casas decimais e o alinhamento.

  • %5d — no mínimo 5 caracteres de largura (preenche com espaços à esquerda).
  • %-5d — largura mínima, alinhado à esquerda (o - muda de lado).
  • %05d — preenche com zeros em vez de espaços.
  • %.2f — exatamente 2 casas decimais.
  • %8.2f — largura 8 e 2 casas decimais.
  • %-8.2f — o mesmo, alinhado à esquerda.
Código — formatando colunas
#include <stdio.h>

int main(void)
{
    int n = 42;
    double r = 3.14159;

    printf("[%5d]\n", n);
    printf("[%-5d]\n", n);
    printf("[%05d]\n", n);
    printf("[%8.2f]\n", r);
    printf("[%-8.2f]\n", r);
    return 0;
}
Saída esperada
[   42]
[42   ]
[00042]
[    3.14]
[3.14    ]

scanf: lendo do teclado (e o mistério do &)

Se printf traduz valores em texto, o scanf faz o caminho inverso: lê texto digitado e guarda em uma variável.

  • int a; scanf("%d", &a); — lê um inteiro e guarda em a.
  • double x; scanf("%lf", &x); — lê um real; repare no lf (é o especificador de leitura de double).
  • Para float usa-se %f na leitura.

Sequências de escape

Dentro de uma string, uma barra invertida seguida de um caractere dá origem a um escape — um caractere especial que não dá para digitar "cru" no texto:

  • \n — quebra de linha (newline).
  • \t — tabulação (tab).
  • \\ — uma barra invertida literal.
  • \" — aspas duplas dentro da string.
  • \0 — o caractere nulo (veremos com strings, na Trilha 2).
Código — escapes
#include <stdio.h>

int main(void)
{
    printf("Linha 1\nLinha 2\n");
    printf("Coluna\tTab\n");
    printf("Contrabarra: \\ \n");
    printf("Aspas: \"C\"\n");
    return 0;
}
Saída esperada
Linha 1
Linha 2
Coluna	Tab
Contrabarra:  
Aspas: "C"

O perigo do tipo errado no printf

Especificador e valor devem casar. Imprimir um double com %d, ou passar um int onde o formato espera %f, é comportamento indefinido: pode sair lixo na tela em uma execução e outra coisa diferente na seguinte. A boa notícia: com a flag -Wall, o gcc aponta a maioria desses erros de formato com um warning — corrija até zerar avisos.

Regra prática: int → %d; char → %c; double/float → %f (no printf). Lendo no scanf: double → %lf, float → %f.

Programa: conversor de temperatura

Vamos juntar tudo: ler um valor de Celsius do teclado, converter para Fahrenheit e imprimir formatado.

Código — temperatura.c
#include <stdio.h>

int main(void)
{
    double celsius;

    printf("Temperatura em Celsius: ");
    scanf("%lf", &celsius);

    printf("%.2f C = %.2f F\n", celsius, celsius * 9.0 / 5.0 + 32.0);
    return 0;
}
Saída esperada
Temperatura em Celsius: 37.5
37.50 C = 99.50 F

Programa: calculadora de área do círculo

E um leitor de raio + cálculo de área. Usamos a constante 3.14159 para não depender de biblioteca matemática nesta trilha.

Código — area.c
#include <stdio.h>

int main(void)
{
    double raio, area;

    printf("Raio do circulo: ");
    scanf("%lf", &raio);

    area = 3.14159 * raio * raio;
    printf("area: %.2f\n", area);
    return 0;
}
Saída esperada
Raio do circulo: 2
area: 12.57

✏️ Exercícios

Nível 2

Exercício 1.03.1

Leia dois números inteiros e imprima a soma e o produto deles, cada um em uma linha com uma frase.

Dica: Dois scanf("%d", &a) e scanf("%d", &b) resolvem.

Ver solução
#include <stdio.h>

int main(void)
{
    int a, b;

    printf("Digite o primeiro numero: ");
    scanf("%d", &a);
    printf("Digite o segundo numero: ");
    scanf("%d", &b);

    printf("soma: %d\n", a + b);
    printf("produto: %d\n", a * b);
    return 0;
}
Nível 2

Exercício 1.03.2

Leia um número real e imprima-o de três formas: com 3 casas decimais, com largura 10 (alinhado à direita) e com largura 10 alinhado à esquerda. Use colchetes para enxergar as larguras.

Dica: %.3f, %10.3f e %-10.3f.

Ver solução
#include <stdio.h>

int main(void)
{
    double x;

    printf("Digite um numero real: ");
    scanf("%lf", &x);

    printf("[%.3f]\n", x);
    printf("[%10.3f]\n", x);
    printf("[%-10.3f]\n", x);
    return 0;
}
Nível 2

Exercício 1.03.3

Leia uma temperatura em Fahrenheit e converta para Celsius usando a fórmula C = (F - 32) * 5 / 9. Imprima com 1 casa decimal.

Dica: Cuidado para não misturar inteiros na fórmula: escreva (f - 32.0) * 5.0 / 9.0.

Ver solução
#include <stdio.h>

int main(void)
{
    double f, c;

    printf("Temperatura em Fahrenheit: ");
    scanf("%lf", &f);

    c = (f - 32.0) * 5.0 / 9.0;
    printf("%.1f F = %.1f C\n", f, c);
    return 0;
}
Nível 2

Exercício 1.03.4

Leia duas notas e imprima a média ponderada, onde a primeira tem peso 2 e a segunda peso 3, com 2 casas decimais.

Dica: média ponderada = (n1*peso1 + n2*peso2) / (peso1 + peso2).

Ver solução
#include <stdio.h>

int main(void)
{
    double n1, n2, media;

    printf("Nota 1: ");
    scanf("%lf", &n1);
    printf("Nota 2: ");
    scanf("%lf", &n2);

    media = (n1 * 2.0 + n2 * 3.0) / (2.0 + 3.0);
    printf("media ponderada: %.2f\n", media);
    return 0;
}
Nível 3

Exercício 1.03.5

Leia um número inteiro e imprima-o em decimal (%d), em hexadecimal (%x) e em octal (%o), com as palavras "dec:", "hex:" e "oct:" antes.

Dica: %o imprime em octal, assim como %x imprime em hexadecimal.

Ver solução
#include <stdio.h>

int main(void)
{
    int n;

    printf("Digite um numero: ");
    scanf("%d", &n);

    printf("dec: %d\n", n);
    printf("hex: %x\n", n);
    printf("oct: %o\n", n);
    return 0;
}

Para 26: decimal 26, hexadecimal 1a, octal 32.

❓ Verificação rápida

🏗️ Miniprojeto: Conta de restaurante

Crie conta.c que lê o valor do consumo (double), a taxa de serviço em % (ex.: 10) e o número de pessoas (int); o programa calcula e imprime o total com serviço e o valor por pessoa, formatados em uma "nota" com larguras e 2 casas decimais. Persona: você é o sistema de um restaurante simples.

Critérios de aceite

  • Lê os três dados com scanf (com & na variável certa).
  • Calcula serviço, total e divisão por pessoa.
  • Imprime como uma nota: cada item em uma linha, valores em colunas alinhadas (largura fixa).
  • Compila com -Wall -Wextra -std=c11 sem avisos.
