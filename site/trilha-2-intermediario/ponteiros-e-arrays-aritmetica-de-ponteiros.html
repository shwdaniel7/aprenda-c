Ponteiros e arrays: aritmética de ponteiros

arrays que decaem para ponteiros, p+n, a[i] == *(a+i), void* e size_t

Nível: Intermediário Duração: ~40 min Pré-requisitos: T2.01

🎯 Objetivos

Entender a equivalência fundamental entre arrays e ponteiros, somar e comparar ponteiros com segurança (stride do tipo), percorrer arrays com ponteiros e dominar ponteiros void* e o tipo size_t.

Arrays decaem para o ponteiro do primeiro elemento

Exceto em alguns contextos (sizeof, &arr), o nome de um array se converte ("decai") para um ponteiro para o seu primeiro elemento. Ou seja: arr na maioria das expressões vale &arr[0].

Código — decai.c
#include <stdio.h>

int main(void)
{
    int arr[5] = {10, 20, 30, 40, 50};

    printf("arr     = %p\n", (void *)arr);
    printf("&arr[0] = %p\n", (void *)&arr[0]);
    printf("iguais? %s\n", arr == &arr[0] ? "sim" : "nao");
    return 0;
}
Saída esperada
arr     = 0000007355BFF990
&arr[0] = 0000007355BFF990
iguais? sim

Aritmética de ponteiros: p + n

Somar um inteiro a um ponteiro não soma 1 byte: soma n × sizeof(tipo). Isso chama-se stride. p + 2 em um int * pula 2 inteiros, ou seja, 8 bytes. É por isso que o tipo do ponteiro importa.

Visualize: p = &arr[0]; então p + 1 é &arr[1], p + 2 é &arr[2], e assim por diante.

Código — aritmetica.c
#include <stdio.h>

int main(void)
{
    int arr[5] = {10, 20, 30, 40, 50};
    int *p = arr;

    for (int i = 0; i < 5; i++) {
        printf("arr[%d] = %2d   p+%d = %p\n", i, arr[i], i, (void *)(p + i));
    }
    return 0;
}
Saída esperada
arr[0] = 10   p+0 = 000000A68A7FFB20
arr[1] = 20   p+1 = 000000A68A7FFB24
arr[2] = 30   p+2 = 000000A68A7FFB28
arr[3] = 40   p+3 = 000000A68A7FFB2C
arr[4] = 50   p+4 = 000000A68A7FFB30

(repare: cada passo soma 4 bytes = sizeof(int))

Percorrendo um array com ponteiro

Com a aritmética pronta, um loop deve percorrer um array com ++p: a variável p "anda" de casa em casa. A condição de parada compara ponteiros — arr + n é o endereço um-passo-além do último elemento (válido para comparar, mas não para dereferenciar).

Código — percorrer.c
#include <stdio.h>

int main(void)
{
    int arr[5] = {10, 20, 30, 40, 50};
    int soma = 0;
    int *p;

    for (p = arr; p < arr + 5; p++) {
        soma += *p;
    }

    printf("soma = %d\n", soma);
    return 0;
}
Saída esperada
soma = 150

Equivalência: a[i] é açúcar para *(a + i)

O compilador trata a[i] como *(a + i) — não é coincidência que os dois escrevam com os mesmos símbolos. Como a adição é comutativa, a[i] e i[a] são tecnicamente a mesma coisa, mas ninguém escreve i[a] em código real.

Código — equivalencia.c
#include <stdio.h>

int main(void)
{
    int arr[5] = {10, 20, 30, 40, 50};

    for (int i = 0; i < 5; i++) {
        printf("arr[%d] = %d    *(arr + %d) = %d\n",
               i, arr[i], i, *(arr + i));
    }
    return 0;
}
Saída esperada
arr[0] = 10    *(arr + 0) = 10
arr[1] = 20    *(arr + 1) = 20
arr[2] = 30    *(arr + 2) = 30
arr[3] = 40    *(arr + 3) = 40
arr[4] = 50    *(arr + 4) = 50

void* e size_t: o ponteiro "maioral" e o tipo de tamanho

void * é um ponteiro sem tipo: serve para transportar endereços sem saber o conteúdo (é o que malloc retorna). Você não pode dereferenciar um void * (o C não sabe quantos bytes ler) — é preciso converter com um cast para o tipo certo.

size_t (em <stddef.h> / <stdlib.h>) é o tipo "sem sinal de tamanho" usado por sizeof, strlen, índices de alocação etc. No printf usamos %zu.

Código — void-e-size.c
#include <stdio.h>
#include <stddef.h>

int main(void)
{
    int x = 7;
    void *pv = &x;
    int *pi = (int *)pv;

    printf("pv = %p\n", pv);
    printf("*pi = %d (apos cast de void* para int*)\n", *pi);
    printf("sizeof(size_t) = %zu\n", sizeof(size_t));
    return 0;
}
Saída esperada
pv = 0000000FD71FFA3C
*pi = 7 (apos cast de void* para int*)
sizeof(size_t) = 8

Nível 1

Exercício 2.02.1

Prove, imprimindo com %p, que arr, &arr[0] e um int *p = arr; têm o mesmo endereço. Repita com um array de double.

Dica: O próprio array decai; imprima os três e compare visualmente.

Ver solução
#include <stdio.h>

int main(void)
{
    int arr[3] = {1, 2, 3};
    double d[3] = {1.5, 2.5, 3.5};
    int *pi = arr;
    double *pd = d;

    printf("arr     = %p   pi     = %p   &arr[0] = %p\n",
           (void *)arr, (void *)pi, (void *)&arr[0]);
    printf("d       = %p   pd     = %p   &d[0]   = %p\n",
           (void *)d, (void *)pd, (void *)&d[0]);
    return 0;
}
Nível 2

Exercício 2.02.2

Some os elementos de um array de 8 inteiros usando apenas um ponteiro com ++ (sem índice). Imprima a soma.

Dica: Loop do padrão for (p = arr; p < arr + 8; p++).

Ver solução
#include <stdio.h>

int main(void)
{
    int arr[8] = {1, 2, 3, 4, 5, 6, 7, 8};
    int soma = 0;
    int *p;

    for (p = arr; p < arr + 8; p++) {
        soma += *p;
    }
    printf("soma = %d\n", soma);
    return 0;
}

Esperado 36. O ponteiro p anda 8 casas de 4 bytes cada.

Nível 3

Exercício 2.02.3

Inverta um array de 6 inteiros in-place usando dois ponteiros (um no início, outro no fim) e a função trocar. Mostre antes e depois.

Dica: Enquanto ini < fim: troque *ini e *fim, depois ini++ e fim--.

Ver solução
#include <stdio.h>

void trocar(int *a, int *b)
{
    int tmp = *a;
    *a = *b;
    *b = tmp;
}

int main(void)
{
    int arr[6] = {1, 2, 3, 4, 5, 6};
    int *ini = arr;
    int *fim = arr + 5;

    printf("original: ");
    for (int i = 0; i < 6; i++) printf("%d ", arr[i]);
    printf("\n");

    while (ini < fim) {
        trocar(ini, fim);
        ini++;
        fim--;
    }

    printf("invertido: ");
    for (int i = 0; i < 6; i++) printf("%d ", arr[i]);
    printf("\n");
    return 0;
}

Saída esperada: original 1 2 3 4 5 6; invertido 6 5 4 3 2 1.

Nível 3

Exercício 2.02.4

Usando apenas ponteiros (nada de []), encontre o menor valor e a posição dele em um array {9, 3, 12, -2, 5, 3}. Imprima o valor e o índice.

Dica: Mantenha p_menor como ponteiro para o menor até agora; no fim, p_menor - arr é o índice.

Ver solução
#include <stdio.h>

int main(void)
{
    int arr[6] = {9, 3, 12, -2, 5, 3};
    int *p_menor = arr;

    for (int *p = arr + 1; p < arr + 6; p++) {
        if (*p < *p_menor) {
            p_menor = p;
        }
    }

    printf("menor valor = %d na posicao %ld\n",
           *p_menor, (long)(p_menor - arr));
    return 0;
}

A subtração de dois ponteiros dá vetor de diferença (tipo ptrdiff_t) — número de elementos entre eles.

Nível 4

Exercício 2.02.5

Uma matriz 2×3 em C é contígua na memória. Percorra mat[2][3] com um único int *p = &mat[0][0], calcule a soma de todos os elementos e ainda imprima o endereço do primeiro e do último.

Dica: &mat[0][0] é o "chão" da grade; p + (2*3) é o fim.

Ver solução
#include <stdio.h>

int main(void)
{
    int mat[2][3] = {{1, 2, 3}, {4, 5, 6}};
    int *p = &mat[0][0];
    int soma = 0;

    for (int *q = p; q < p + 6; q++) {
        soma += *q;
    }

    printf("soma = %d\n", soma);
    printf("primeiro: %p   derradeiro: %p\n",
           (void *)p, (void *)(p + 5));
    return 0;
}

Esperado soma = 21. Matrizes 2D são "arrays de arrays" contíguos: 2 blocos de 3 ints seguidos.
