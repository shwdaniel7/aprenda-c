Funções variádicas: va_list

<stdarg.h>, ... , va_start/va_arg/va_end, promoções e a família v*

Nível: Intermediário Duração: ~40 min Pré-requisitos: T2.13

🎯 Objetivos

Escrever suas próprias funções de número variável de argumentos — como o printf — usando ; entender as promoções de argumento padrão (char→int, float→double) e reutilizar format strings com segurança através de vprintf, vfprintf e vsnprintf.

Foco da leitura: No Beej, leia a seção de variadic functions com va_start/va_arg/va_end e a tabela de promoções. No King, o contexto de printf/scanf mostra onde nascem os argumentos variáveis na biblioteca padrão.

O problema: número variável de argumentos

printf é o caso da vida: às vezes imprime 1 valor, às vezes 5, às vezes 100. Assinaturas rígidas como f(int, int) não cobrem isso. A resposta do C são as funções variádicas: uma função que aceita uma quantidade variável de argumentos, declarada com reticências ... no fim.

O suporte fica em <stdarg.h>. A partir deste módulo, o printf deixa de ser caixa preta — e você ganha o poder de fazer os seus próprios.

Código — por-que.c
#include <stdio.h>

int main(void)
{
    printf("printf com 1 argumento\n");
    printf("com 2 argumentos: x=%d\n", 7);
    printf("com 3 argumentos: %d + %d = %d\n", 2, 3, 5);
    return 0;
}
Saída esperada
> gcc -Wall -Wextra -std=c11 por-que.c -o por-que
> .\por-que.exe

printf com 1 argumento
com 2 argumentos: x=7
com 3 argumentos: 2 + 3 = 5

Anatomia: va_list, va_start, va_arg, va_end

Uma função variádica tem pelo menos um parâmetro fixo e as reticências: int soma(int n, ...). Dentro dela o ritual tem quatro passos: (1) declarar uma va_list ap; (2) va_start(ap, n) — "a lista começa logo depois do parâmetro fixo n"; (3) a cada va_arg(ap, int), o próximo argumento é devolvido já no tipo pedido; (4) va_end(ap) no fim — obrigatório, ele limpa o estado interno.

O tipo que você pede em va_arg precisa bater com o argumento de verdade; e a quantidade fica por sua conta — o parâmetro fixo normalmente carrega a contagem. Errar o tipo ou a contagem é comportamento indefinido.

Código — soma-variadica.c
#include <stdio.h>
#include <stdarg.h>

int soma(int n, ...)
{
    va_list ap;
    va_start(ap, n);

    int total = 0;
    for (int i = 0; i < n; i++) {
        total += va_arg(ap, int);
    }

    va_end(ap);
    return total;
}

int main(void)
{
    printf("soma(3, 10, 20, 30) = %d\n", soma(3, 10, 20, 30));
    printf("soma(5, 1..5)       = %d\n", soma(5, 1, 2, 3, 4, 5));
    printf("soma(0)             = %d\n", soma(0));
    return 0;
}
Saída esperada
> gcc -Wall -Wextra -std=c11 soma-variadica.c -o soma
> .\soma.exe

soma(3, 10, 20, 30) = 60
soma(5, 1..5)       = 15
soma(0)             = 0

Promoções de argumento padrão

Antes de chegar a uma função variádica, cada argumento passa pelas default argument promotions: char, short e enum sobem para int; float sobe para double. Nenhum argumento "chega float" — ele vira double na viagem.

Consequência prática: va_arg(ap, float) é sempre errado. Se o argumento era float, chegou double; é o double que você pede. (Não rodamos esse UB de propósito: basta saber que ler float onde existe double é lixo.) O exemplo lê corretamente os dois casos: ints promovidos e doubles.

Código — promocoes.c
#include <stdio.h>
#include <stdarg.h>

void mostrar_promovidos(int n, ...)
{
    va_list ap;
    va_start(ap, n);
    for (int i = 0; i < n; i++) {
        int v = va_arg(ap, int);
        printf("arg %d promovido a int: %d\n", i, v);
    }
    va_end(ap);
}

void mostrar_doubles(int n, ...)
{
    va_list ap;
    va_start(ap, n);
    for (int i = 0; i < n; i++) {
        double v = va_arg(ap, double);
        printf("arg %d chega como double: %.3f\n", i, v);
    }
    va_end(ap);
}

int main(void)
{
    char c = 'A';
    short s = 300;

    mostrar_promovidos(3, c, s, 42);
    mostrar_doubles(2, 1.5f, 2.75f);
    return 0;
}
Saída esperada
> gcc -Wall -Wextra -std=c11 promocoes.c -o promocoes
> .\promocoes.exe

arg 0 promovido a int: 65
arg 1 promovido a int: 300
arg 2 promovido a int: 42
arg 0 chega como double: 1.500
arg 1 chega como double: 2.750

(o char 'A' chegou como 65; o short 300, como 300; os floats chegaram como double)

A família v*: format strings reutilizáveis

Com uma va_list pronta, dá para formatar reusando o motor do printf: vprintf (stdout), vfprintf (um FILE *) e vsnprintf (um buffer, com limite). Elas recebem a va_list "no lugar das reticências".

O padrão de ouro: sua função variádica recebe o formato, chama va_start e entrega a lista para a versão v* — um único ponto centralizado de formatação, em vez de repetir format string a cada chamada.

Código — vlog.c
#include <stdio.h>
#include <stdarg.h>

void log_event(const char *nivel, const char *fmt, ...)
{
    FILE *f = fopen("eventos.log", "a");
    if (f == NULL) {
        return;
    }

    fprintf(f, "[%s] ", nivel);
    va_list ap;
    va_start(ap, fmt);
    vfprintf(f, fmt, ap);
    va_end(ap);
    fprintf(f, "\n");
    fclose(f);
}

int main(void)
{
    log_event("INFO", "inicio do programa");
    log_event("ERRO", "operacao %d falhou na etapa %d", 7, 2);
    log_event("INFO", "concluido com %d itens", 42);

    FILE *f = fopen("eventos.log", "r");
    if (f == NULL) {
        return 1;
    }
    char linha[256];
    while (fgets(linha, sizeof linha, f) != NULL) {
        printf("%s", linha);
    }
    fclose(f);
    return 0;
}
Saída esperada
> gcc -Wall -Wextra -std=c11 vlog.c -o vlog
> .\vlog.exe

[INFO] inicio do programa
[ERRO] operacao 7 falhou na etapa 2
[INFO] concluido com 42 itens

(o log é aberto em modo append: rode o exe de novo e o arquivo eventos.log ganha mais 3 linhas)

Armadilhas e segurança

Regra número um: em va_arg, peça exatamente o tipo que chegou após as promoções — erro aí é comportamento indefinido. Regra número dois: quem garante que a quantidade de argumentos bate com o formato é você; nada impede ninguém de mandar %s sem a string.

A armadilha mais grave é deixar o usuário controlar a format string: printf(entrada_do_usuario). Um usuário malicioso injeta %x para vazar memória do stack ou %n para escrever na memória — é a origem da classe de vulnerabilidades de format strings, estudada a fundo na Trilha 4. A forma correta é sempre formatar com formato fixo e passar o texto como dado: printf("%s", entrada).

Código — format-perigo.c
#include <stdio.h>

int main(void)
{
    char buf[128];

    printf("Escreva algo: ");
    if (fgets(buf, sizeof buf, stdin) == NULL) {
        return 1;
    }

    printf(buf);          /* PERIGOSO: usuario controla a format string */
    printf("%s", buf);    /* seguro: a string vira dado, nao formato */
    return 0;
}
Saída esperada
> gcc -Wall -Wextra -std=c11 format-perigo.c -o format-perigo
> echo oi | .\format-perigo.exe

Escreva algo: oi
oi

(com entrada benigna as duas impressoes coincidem. Troque o input por "%x %x %x %x": a primeira impressao despeja lixo da pilha/registradores; "%n" escreve na memoria. E a Trilha 4.)

Nível 2

Exercício 2.14.1

Escreva int soma(int n, ...) e use-a para somar 4 números (1, 2, 3, 4) e 6 números (5, 10, 15, 20, 25, 30). Imprima os dois resultados.

Dica: Parâmetro fixo n + va_start, laço com va_arg(ap, int) e va_end.

Ver solução
#include <stdio.h>
#include <stdarg.h>

int soma(int n, ...)
{
    va_list ap;
    va_start(ap, n);

    int total = 0;
    for (int i = 0; i < n; i++) {
        total += va_arg(ap, int);
    }

    va_end(ap);
    return total;
}

int main(void)
{
    int r1 = soma(4, 1, 2, 3, 4);
    int r2 = soma(6, 5, 10, 15, 20, 25, 30);

    printf("soma(1, 2, 3, 4)         = %d\n", r1);
    printf("soma(5, 10, 15, 20, 25, 30) = %d\n", r2);
    return 0;
}

Esperado 10 e 105.

Nível 2

Exercício 2.14.2

Escreva int maximo(int n, ...) que devolve o maior entre n inteiros. Teste com (7, 12, 4, 9), com os negativos (-5, -2, -9) e com um único 42.

Dica: Comece o máximo com o primeiro va_arg e compare os demais. Sua API deve exigir n ≥ 1.

Ver solução
#include <stdio.h>
#include <stdarg.h>

int maximo(int n, ...)
{
    va_list ap;
    va_start(ap, n);

    int m = va_arg(ap, int);
    for (int i = 1; i < n; i++) {
        int x = va_arg(ap, int);
        if (x > m) {
            m = x;
        }
    }

    va_end(ap);
    return m;
}

int main(void)
{
    printf("maximo(4, 7, 12, 4, 9)   = %d\n", maximo(4, 7, 12, 4, 9));
    printf("maximo(3, -5, -2, -9)    = %d\n", maximo(3, -5, -2, -9));
    printf("maximo(1, 42)            = %d\n", maximo(1, 42));
    return 0;
}

Esperado 12, -2 e 42.

Nível 3

Exercício 2.14.3

Crie void log_format(const char *nivel, const char *fmt, ...) que abre log.txt em modo "a" e grava uma linha com hora atual (time.h), o nível e a mensagem formatada por vfprintf. Registre um INFO, um WARN e um ERRO e depois imprima o log.

Dica: Monte o tempo com time(NULL) + localtime + strftime; o "charme" da v* é o vfprintf.

Ver solução
#include <stdio.h>
#include <stdarg.h>
#include <time.h>

void log_format(const char *nivel, const char *fmt, ...)
{
    FILE *f = fopen("log.txt", "a");
    if (f == NULL) {
        return;
    }

    time_t agora = time(NULL);
    struct tm *info = localtime(&agora);
    char tempo[32];
    strftime(tempo, sizeof tempo, "%Y-%m-%d %H:%M:%S", info);

    fprintf(f, "%s [%s] ", tempo, nivel);

    va_list ap;
    va_start(ap, fmt);
    vfprintf(f, fmt, ap);
    va_end(ap);

    fprintf(f, "\n");
    fclose(f);
}

int main(void)
{
    log_format("INFO", "configuracoes carregadas");
    log_format("WARN", "valor %d acima do limite %d", 150, 100);
    log_format("ERRO", "arquivo \"%s\" nao encontrado", "dados.conf");

    FILE *f = fopen("log.txt", "r");
    if (f == NULL) {
        return 1;
    }
    char linha[256];
    while (fgets(linha, sizeof linha, f) != NULL) {
        printf("log: %s", linha);
    }
    fclose(f);
    return 0;
}

O timestamp muda a cada execução — é a hora real da gravação. O resto do texto você controla pelo formato.

Nível 3

Exercício 2.14.4

Implemente char *formatar(const char *fmt, ...) que produz o texto num buffer alocado no heap com duas passadas de vsnprintf: a primeira com tamanho 0 só para descobrir o tamanho (o retorno), a segunda para escrever de verdade. Teste com "%s tem %d anos" e "media %.2f de %d provas".

Dica: vsnprintf(NULL, 0, fmt, ap) devolve quantos bytes seriam necessários. Use va_copy quando precisar da lista mais de uma vez.

Ver solução
#include <stdio.h>
#include <stdlib.h>
#include <stdarg.h>

char *formatar(const char *fmt, ...)
{
    va_list ap, ap2;

    va_start(ap, fmt);
    va_copy(ap2, ap);
    int tam = vsnprintf(NULL, 0, fmt, ap);
    va_end(ap);

    if (tam < 0) {
        va_end(ap2);
        return NULL;
    }

    char *buf = malloc((size_t)tam + 1);
    if (buf == NULL) {
        va_end(ap2);
        return NULL;
    }

    vsnprintf(buf, (size_t)tam + 1, fmt, ap2);
    va_end(ap2);
    return buf;
}

int main(void)
{
    char *s1 = formatar("%s tem %d anos", "Leo", 23);
    char *s2 = formatar("media %.2f de %d provas", 8.75, 4);

    if (s1 != NULL) {
        printf("%s\n", s1);
        free(s1);
    }
    if (s2 != NULL) {
        printf("%s\n", s2);
        free(s2);
    }
    return 0;
}

O retorno de vsnprintf é o tamanho que seria escrito, mesmo com truncamento; aloque esse valor + 1 para o \0. A memória é sua: free depois.

Nível 4

Exercício 2.14.5

Escreva char *juntar(int n, const char *sep, ...) que concatena n strings com sep entre elas, usando vsnprintf em duas passadas: construa uma format string com %s e separadores, meça com vsnprintf(NULL, 0, ...) e depois escreva. Ex.: juntar(4, " - ", "azul","verde","amarelo","vermelho") deve dar "azul - verde - amarelo - vermelho".

Dica: Construa fmt como "%s - %s - %s - %s" a partir de sep e n, depois rode vsnprintf duas vezes recomeçando o va_start.

Ver solução
#include <stdio.h>
#include <stdlib.h>
#include <stdarg.h>
#include <string.h>

char *juntar(int n, const char *sep, ...)
{
    size_t fmt_cap = 2 + (size_t)(n > 0 ? (n - 1) : 0) * (strlen(sep) + 2);
    char *fmt = malloc(fmt_cap + 1);
    if (fmt == NULL) {
        return NULL;
    }

    int p = 0;
    for (int i = 0; i < n; i++) {
        p += snprintf(fmt + p, fmt_cap + 1 - (size_t)p,
                      i > 0 ? "%s%%s" : "%%s", i > 0 ? sep : "");
    }

    va_list ap;
    va_start(ap, sep);
    int tam = vsnprintf(NULL, 0, fmt, ap);
    va_end(ap);

    char *buf = NULL;
    if (tam >= 0) {
        buf = malloc((size_t)tam + 1);
        if (buf != NULL) {
            va_start(ap, sep);
            vsnprintf(buf, (size_t)tam + 1, fmt, ap);
            va_end(ap);
        }
    }

    free(fmt);
    return buf;
}

int main(void)
{
    char *j = juntar(4, " - ", "azul", "verde", "amarelo", "vermelho");
    if (j != NULL) {
        printf("%s\n", j);
        free(j);
    }

    j = juntar(3, ",", "a", "b", "c");
    if (j != NULL) {
        printf("%s\n", j);
        free(j);
    }
    return 0;
}

Não confie que a libc avance a sua va_list entre chamadas de vsnprintf — por isso as duas passadas recomeçam com va_start (ou va_copy).

🏗️ Miniprojeto: Mini-biblioteca de logging

Implemente log.h/log.c e um main.c de teste. A biblioteca expõe void log_msg(int nivel, const char *fmt, ...) com níveis ERROR/WARN/INFO via enum; a função grava em app.log uma linha com timestamp (time.h), o texto do nível e a mensagem formatada por vfprintf. Suporte também um limiar configurável: mensagens de nível abaixo do mínimo são descartadas.

Critérios de aceite

  • log.h com include guard (T2.08) e log.c com a implementação real de log_msg.
  • Níveis ERROR/WARN/INFO via enum; a linha impressa traz o nome do nível por extenso.
  • Timestamp com time.h (strftime) no formato "YYYY-MM-DD HH:MM:SS".
  • Limiar configurável (ex.: log_set_level) — nível abaixo do limiar não grava.
  • Várias execuções anexam ao mesmo app.log sem corromper nada (modo "a" + fclose conferido).
  • Compila com gcc -Wall -Wextra -std=c11 log.c main.c -o app sem avisos.
