2.03

Strings em C

char[] + '\0', literais, char*, fgets vs gets, scanf %s e strlen

Nível: Intermediário Duração: ~35 min Pré-requisitos: T2.01 e T2.02

🎯 Objetivos

Saber que uma string em C é um array de char terminado em '\0', diferenciar array vs literal imutável, ler entradas de forma segura com fgets e percorrer strings com ponteiros.

String = array de char terminado em \0

No C, "string" é uma convenção: um array de char terminado em '\0' (byte 0). O tamanho da string não é guardado em lugar nenhum — o código para ao encontrar o \0. Por isso "tamanho do array" (sizeof) e "tamanho da string" (strlen) são coisas diferentes: o array inclui o \0.

Um string literal ("Ana") gera um array estático só de leitura — tentar modificar é comportamento indefinido. Para ter uma string modificável, copiamos os caractéres para um array próprio:

Código — literal.c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char nome1[] = "Ana";        /* array de 4: 'A','n','a','\0' */
    char *nome2 = "Ana";         /* ponteiro para literal (read-only) */
    char copia[] = "Software Livre";

    nome1[0] = 'B';              /* ok: nome1 eh uma copia propria */
    /* nome2[0] = 'B'; */        /* proibido: literal e read-only */

    printf("nome1 (array)   = %s\n", nome1);
    printf("nome2 (literal) = %s\n", nome2);
    printf("strlen(nome1) = %zu\n", strlen(nome1));
    printf("sizeof(nome1) = %zu (inclui o '\\0')\n", sizeof nome1);
    printf("len da string = %zu, bytes do array = %zu\n",
           strlen(copia), sizeof copia);
    return 0;
}
Saída esperada
nome1 (array)   = Bna
nome2 (literal) = Ana
strlen(nome1) = 3
sizeof(nome1) = 4 (inclui o '\0')
len da string = 14, bytes do array = 15

Lendo com fgets: seguro, mas cuidado com o \n

A função gets é proibida (nem existe mais no padrão): ela não tem como saber o tamanho do buffer e estoura a memória. Use fgets(buffer, tamanho, stdin), que lê no máximo tamanho-1 caracteres e sempre coloca o \0.

Charme do fgets: ele guarda a nova linha pressionada no buffer. Removê-la é trabalho nosso — um truque comum é o strcspn (módulo T2.04) ou um loop que localiza o '\n':

Código — fgets.c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char nome[100];

    printf("Digite seu nome: ");
    if (fgets(nome, sizeof nome, stdin) == NULL) {
        return 1;
    }

    nome[strcspn(nome, "\n")] = '\0';   /* remove a quebra de linha */

    printf("Ola, %s!\n", nome);
    printf("A string tem %zu caracteres.\n", strlen(nome));
    return 0;
}
Saída esperada
Digite seu nome: Daniel
Ola, Daniel!
A string tem 6 caracteres.

scanf %s: rápido, com limitações

scanf("%s", buf) lê uma palavra (para no primeiro espaço) e não valida o tamanho — com um campo de largura como %99s limitamos a 99 caracteres, evitando estouro. A grande limitação: ele para no espaço, então não serve para ler frases.

Código — scanf-string.c
#include <stdio.h>

int main(void)
{
    char nome[100];
    int idade;

    printf("Digite nome e idade: ");
    if (scanf("%99s %d", nome, &idade) != 2) {
        return 1;
    }

    printf("Nome: %s\n", nome);
    printf("Idade: %d\n", idade);
    return 0;
}
Saída esperada
Digite nome e idade: Maria 28
Nome: Maria
Idade: 28

(tente digitar "Ana Clara Souza 28": só "Ana" é lido como nome)

Percorrendo uma string com ponteiro

Como a string é um array terminado em \0, o padrão for (p = s; *p != '\0'; p++) anda casa por casa até a sentinela. Veja a contagem de caracteres feita à mão (o que a strlen faz por dentro):

Código — percorrer.c
#include <stdio.h>

int tamanho(const char *s)
{
    int n = 0;
    while (s[n] != '\0') {
        n++;
    }
    return n;
}

int main(void)
{
    const char *msg = "caminho";

    printf("tamanho(\"%s\") = %d\n", msg, tamanho(msg));

    printf("letras: ");
    for (const char *p = msg; *p != '\0'; p++) {
        printf("%c ", *p);
    }
    printf("\n");
    return 0;
}
Saída esperada
tamanho("caminho") = 7
letras: c a m i n h o

✏️ Exercícios

Nível 1

Exercício 2.03.1

Escreva sua própria comprimento (parecida com strlen) que conta caracteres até o \0. Teste com "ada", "programacao" e "" (string vazia).

Dica: loop while (s[n] != '\0') n++;

Ver solução
#include <stdio.h>

int comprimento(const char *s)
{
    int n = 0;
    while (s[n] != '\0') {
        n++;
    }
    return n;
}

int main(void)
{
    printf("\"ada\"          -> %d\n", comprimento("ada"));
    printf("\"programacao\"  -> %d\n", comprimento("programacao"));
    printf("\"\" (vazia)     -> %d\n", comprimento(""));
    return 0;
}

Esperado: 3, 11 e 0. Note que a string vazia tem só o \0.

Nível 2

Exercício 2.03.2

Leia o nome do usuário com fgets, remova o \n e imprima uma saudação com a quantidade de letras, ex.: "Olá, JULIA! Seu nome tem 5 letras."

Dica: Use strcspn para achar o \n e strlen para contar.

Ver solução
#include <stdio.h>
#include <string.h>

int main(void)
{
    char nome[100];

    printf("Digite seu nome: ");
    if (fgets(nome, sizeof nome, stdin) == NULL) {
        return 1;
    }
    nome[strcspn(nome, "\n")] = '\0';

    printf("Ola, %s!  Seu nome tem %zu letras.\n",
           nome, strlen(nome));
    return 0;
}
Nível 3

Exercício 2.03.3

Implemente seu próprio copiar (clone de strcpy) que copia o conteúdo de origem para destino incluindo o \0. Teste copiando "linguagem" para um buffer e imprima.

Dica: O clássico: while ((*dest++ = *src++)) ; — para quando copiar o \0. Ou um loop simples por índice.

Ver solução
#include <stdio.h>

void copiar(char *dest, const char *src)
{
    int i = 0;
    while (src[i] != '\0') {
        dest[i] = src[i];
        i++;
    }
    dest[i] = '\0';
}

int main(void)
{
    char copia[32];

    copiar(copia, "linguagem");
    printf("copia = \"%s\"\n", copia);
    return 0;
}

Garanta que destino tem espaço suficiente (>= strlen(origem)+1).

Nível 3

Exercício 2.03.4

Escreva contar_vogais que conta as vogais (a, e, i, o, u, ignorando maiúsculas) de uma string. Teste com "Programacao em C".

Dica: Compare cada char já normalizado com tolower ou faça duas listas (maiúsculas e minúsculas).

Ver solução
#include <stdio.h>
#include <ctype.h>

int contar_vogais(const char *s)
{
    int total = 0;
    for (; *s != '\0'; s++) {
        char c = (char)tolower((unsigned char)*s);
        if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u') {
            total++;
        }
    }
    return total;
}

int main(void)
{
    printf("vogais em \"Programacao em C\": %d\n",
           contar_vogais("Programacao em C"));
    return 0;
}

Resultado esperado: 7 vogais.

Nível 4

Exercício 2.03.5

Inverta uma string in-place com dois ponteiros, um no início e outro no fim. Cuidado para não inverter o \0! Teste com "abcdefg".

Dica: fim deve apontar para o último caractere, ou seja, base + comprimento - 1.

Ver solução
#include <stdio.h>

void trocar(char *a, char *b)
{
    char tmp = *a;
    *a = *b;
    *b = tmp;
}

int main(void)
{
    char texto[] = "abcdefg";
    char *ini = texto;
    char *fim = texto;

    while (*fim != '\0') {
        fim++;
    }
    fim--;                     /* para no ultimo caractere */

    while (ini < fim) {
        trocar(ini, fim);
        ini++;
        fim--;
    }

    printf("invertida: %s\n", texto);
    return 0;
}

Esperado "gfedcba". Crucial: começar o fim no último caractere, nunca apontar o fim para o \0 durante a troca.

🏗️ Miniprojeto: Leitor de frases amigável

Crie um programa que pergunta três frases (uma por linha, com fgets), remove as quebras de linha, e depois imprime: a frase mais longa (com posição), a frase mais curta, e a soma total de caracteres. Faça sem usar strlen em pelo menos uma parte (uma função própria de tamanho) e com ponteiros para comparar.

Critérios de aceite

  • Entrada 100% com fgets (sem scanf %s no texto final).
  • Função própria de tamanho + uso de strlen em outro trecho.
  • Impressão das frases na ordem digitada e dos resultados pedidos.
  • Compila com -Wall -Wextra sem avisos.
