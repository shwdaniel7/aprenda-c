Ponteiros: o coração do C

endereços, operador &, dereferência, NULL e retorno múltiplo

Nível: Intermediário Duração: ~45 min Pré-requisitos: T1.06 a T1.08 (arrays, loops e funções)

🎯 Objetivos

A memória e o endereço das variáveis

Imagine a memória RAM como uma rua com milhões de casas numeradas. Cada byte tem um endereço — um número que diz onde ele está. Quando você declara int x = 42;, o compilador reserva 4 bytes em algum lugar dessa rua e associa o nome x a esse endereço.

O operador unário & (e-comercial) devolve o endereço de uma variável. É como perguntar "qual casa o x mora?". O especificador %p imprime um endereço (elemento tem de ser disparado como void *):

Código — endereco.c
#include <stdio.h>

int main(void)
{
    int x = 42;
    char c = 'A';
    double d = 3.14;

    printf("x = %d, &x = %p\n", x, (void *)&x);
    printf("c = %c, &c = %p\n", c, (void *)&c);
    printf("d = %.2f, &d = %p\n", d, (void *)&d);
    return 0;
}
Saída esperada
x = 42, &x = 000000A177BFFDCC
c = A, &c = 000000A177BFFDCB
d = 3.14, &d = 000000A177BFFDC0

(as casas são números longos; endereços mudam a cada execução. x, c e d ficaram pertinhos no stack)

Ponteiro: uma caixa que guarda um endereço

Um ponteiro é exatamente isso: uma variável cujo conteúdo é um endereço. A declaração int *p; lê-se "p é um ponteiro para int". Diagrama mental: uma caixa com um bilhete escrito &x.

Para pegar o endereço usamos &x; para seguir para a casa (ler ou escrever no valor apontado) usamos o operador unário *, chamado dereferência:

Código — primeiro-ponteiro.c
#include <stdio.h>

int main(void)
{
    int x = 42;
    int *p = &x;

    printf("x = %d\n", x);
    printf("&x = %p\n", (void *)&x);
    printf("p = %p\n", (void *)p);
    printf("*p = %d\n", *p);

    *p = 7;              /* escreve no mesmo endereço de x */
    printf("depois de *p = 7 -> x = %d\n", x);
    return 0;
}
Saída esperada
x = 42
&x = 000000A8D05FFA34
p = 000000A8D05FFA34
*p = 42
depois de *p = 7 -> x = 7

(p e &x imprimem o mesmo número: p guarda o endereço de x)

Por que o tipo do ponteiro importa

int *p e char *p guardam endereços do mesmo tamanho (8 bytes em 64 bits). Então por que o tipo? Porque * precisa saber quantos bytes e como interpretá-los na casa apontada: um int ocupa 4 bytes; um char, 1. O tipo define a "unidade" da casa.

O exemplo abaixo olha os bytes por dentro de um int usando um char *. Em máquinas little-endian (x86/x64), o byte menos significativo vem primeiro:

Código — tipos.c
#include <stdio.h>

int main(void)
{
    int x = 1000;               /* 0x000003E8 */
    int *pi = &x;
    char *pc = (char *)&x;

    printf("sizeof(ponteiro) = %zu bytes\n", sizeof(pi));
    printf("*pi = %d\n", *pi);
    printf("primeiro byte via char* = %d\n", (int)*pc);
    printf("bytes do int: %02X %02X %02X %02X\n",
           (unsigned char)pc[0], (unsigned char)pc[1],
           (unsigned char)pc[2], (unsigned char)pc[3]);
    return 0;
}
Saída esperada
sizeof(ponteiro) = 8 bytes
*pi = 1000
primeiro byte via char* = -24
bytes do int: E8 03 00 00

(o byte 0xE8 visto como unsigned char seria 232; como char com sinal aparece -24)

Ponteiro que não aponta para nada: NULL

Um ponteiro não inicializado guarda lixo — dereferenciá-lo é comportamento indefinido (crash). Por isso a linguagem fornece NULL: um valor sentinela garantidamente inválido que significa "não aponto para lugar nenhum". Compare com NULL antes de usar, e use NULL após um free para não "seguir" um ponteiro já apagado.

Código — nulo.c
#include <stdio.h>

int main(void)
{
    int *p = NULL;

    if (p == NULL) {
        printf("p ainda nao aponta para lugar nenhum.\n");
    }

    int x = 5;
    p = &x;
    printf("depois de p = &x, *p = %d\n", *p);
    return 0;
}
Saída esperada
p ainda nao aponta para lugar nenhum.
depois de p = &x, *p = 5

Swap: funções que modificam quem chamou

Em C, funções recebem cópias dos argumentos. Por isso trocar(a, b) com valores não muda nada lá fora. A solução clássica é passar endereços: a função segue o bilhete e mexe na casa original.

Este é o ponto de virada para "retornar" múltiplos valores: em vez de um return, você recebe endereços de variáveis do chamador e escreve nelas.

Código — swap.c
#include <stdio.h>

void trocar(int *a, int *b)
{
    int tmp = *a;
    *a = *b;
    *b = tmp;
}

int main(void)
{
    int x = 10, y = 99;
    printf("antes : x=%d y=%d\n", x, y);
    trocar(&x, &y);
    printf("depois: x=%d y=%d\n", x, y);
    return 0;
}
Saída esperada
antes : x=10 y=99
depois: x=99 y=10

Devolvendo dois resultados: quociente e resto

A mesma técnica resolve o caso de uma operação que produz dois resultados. Aqui divide "devolve" o quociente e o resto por meio de dois ponteiros — nenhum return é necessário.

Observe ainda dois detalhes do C: -17 / 5 trunca em direção a zero (dá -3), e o resto acompanha o sinal do dividendo (dá -2). Programas científicos de verdade desenham as regras de arredondamento de propósito.

Código — divisao-com-resto.c
#include <stdio.h>

void divide(int a, int b, int *quociente, int *resto)
{
    *quociente = a / b;
    *resto = a % b;
}

int main(void)
{
    int q, r;
    divide(17, 5, &q, &r);
    printf("17 / 5  = %d, resto %d\n", q, r);
    divide(-17, 5, &q, &r);
    printf("-17 / 5 = %d, resto %d\n", q, r);
    return 0;
}
Saída esperada
17 / 5  = 3, resto 2
-17 / 5 = -3, resto -2

✏️ Exercícios

Nível 1

Exercício 2.01.1

Declare um int, um char e um double, imprima os três valores e os três endereços com %p. Imprima também sizeof(int*) e sizeof(char*). Rode o programa algumas vezes: os endereços mudam? O sizeof muda?

Dica: Imprima endereço sempre com (void *) no argumento do %p.

Ver solução
#include <stdio.h>

int main(void)
{
    int x = 1;
    char c = 'z';
    double d = 2.5;

    printf("x = %d  &x = %p\n", x, (void *)&x);
    printf("c = %c  &c = %p\n", c, (void *)&c);
    printf("d = %.2f &d = %p\n", d, (void *)&d);

    printf("sizeof(int*)  = %zu\n", sizeof(int *));
    printf("sizeof(char*) = %zu\n", sizeof(char *));
    return 0;
}

Os endereços variam a cada execução (o sistema posiciona o stack onde quiser); o sizeof depende da arquitetura (8 em 64 bits).

Nível 2

Exercício 2.01.2

Escreva a função trocar e use-a para inverter os valores de duas variáveis lidas de um array, mostrando o array antes e depois (ex.: arr = {5, 9} vira {9, 5}).

Dica: Um array decai para o endereço do primeiro elemento; você pode passar &arr[0] e &arr[1].

Ver solução
#include <stdio.h>

void trocar(int *a, int *b)
{
    int tmp = *a;
    *a = *b;
    *b = tmp;
}

int main(void)
{
    int arr[2] = {5, 9};

    printf("antes : arr[0]=%d arr[1]=%d\n", arr[0], arr[1]);
    trocar(&arr[0], &arr[1]);
    printf("depois: arr[0]=%d arr[1]=%d\n", arr[0], arr[1]);
    return 0;
}
Nível 3

Exercício 2.01.3

Gere quociente e resto de 29 ÷ 7 e também de -29 ÷ 7 usando uma função com ponteiros. Imprima resultados em formato a / b = q, resto r.

Dica: A função divide acima já faz isso — basta adaptar os valores.

Ver solução
#include <stdio.h>

void divide(int a, int b, int *q, int *r)
{
    *q = a / b;
    *r = a % b;
}

int main(void)
{
    int q, r;
    divide(29, 7, &q, &r);
    printf("29 / 7 = %d, resto %d\n", q, r);
    divide(-29, 7, &q, &r);
    printf("-29 / 7 = %d, resto %d\n", q, r);
    return 0;
}

Esperado: 29/7 = 4 resto 1; -29/7 = -4 resto -1 (truncamento em direção a zero).

Nível 3

Exercício 2.01.4

Escreva estatisticas(a, b, c, &menor, &maior) que devolve, pelos ponteiros, o menor e o maior de três inteiros. Teste com valores com negativos e repita com ordem trocada.

Dica: Comece com *menor = a e *maior = a, depois compare com b e c.

Ver solução
#include <stdio.h>

void estatisticas(int a, int b, int c, int *menor, int *maior)
{
    *menor = a;
    *maior = a;

    if (b < *menor) *menor = b;
    if (b > *maior) *maior = b;
    if (c < *menor) *menor = c;
    if (c > *maior) *maior = c;
}

int main(void)
{
    int mn, mx;
    estatisticas(-3, 12, 0, &mn, &mx);
    printf("entre -3, 12 e 0: menor=%d maior=%d\n", mn, mx);
    estatisticas(7, 7, 1, &mn, &mx);
    printf("entre 7, 7 e 1: menor=%d maior=%d\n", mn, mx);
    return 0;
}
Nível 4

Exercício 2.01.5

Escreva uma função apontar_para(int **pp, int *alvo) que muda para onde o ponteiro do chamador aponta (dica: receba o endereço do próprio ponteiro). No main, faça p apontar para a, imprima *p, chame a função com &p e &b, e imprima *p de novo.

Dica: Isso é um ponteiro-para-ponteiro: **pp é o ponteiro original; *pp = alvo troca o ponteiro do chamador.

Ver solução
#include <stdio.h>

void apontar_para(int **pp, int *alvo)
{
    *pp = alvo;
}

int main(void)
{
    int a = 10, b = 20;
    int *p = &a;

    printf("p aponta para %d\n", *p);
    apontar_para(&p, &b);
    printf("p agora aponta para %d\n", *p);
    return 0;
}

A mesma ideia de passar o endereço da caixa que você quer alterar — aqui a caixa guarda um ponteiro. Esse padrão será explorado no módulo T2.11 e no strtok.

❓ Verificação rápida

🏗️ Miniprojeto: Caixa registradora: troco em cédulas

Implemente a função troco(int valor, int *c100, int *c50, int *c20, int *c10, int *c5, int *c2, int *c1) que preenche a menor quantidade de cédulas/moedas para pagar um valor. No main, teste com 289, 117 e 30 e imprima o "extrato". Vale também validar que a soma das cédulas multiplicadas pelos valores bate com o total.

Critérios de aceite

  • Função usa ponteiros para "devolver" as sete quantidades.
  • Menu/testes cobrem valores variados (incluindo múltiplos de 5 e ímpares).
  • Verificação de soma: 100*c100 + 50*c50 + ... + 1*c1 == valor informado.
  • Compila com gcc -Wall -Wextra -std=c11 sem avisos.
