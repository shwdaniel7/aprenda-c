O pré-processador

#include, #define, macros com parênteses, #ifdef e guardas

Nível: Intermediário Duração: ~45 min Pré-requisitos: T2.01 a T2.07

🎯 Objetivos

#include, #define e o "repeat" do texto

O pré-processador roda antes do compilador e é, na prática, um "substituidor de texto". #include cola o conteúdo de um arquivo (<...> procura em diretórios de sistema; "..." procura na pasta atual). #define cria macros — constantes ou "mini-funções" textuais.

Parênteses, parênteses, parênteses: toda macro com argumentos envolve cada parâmetro e o corpo inteiro em parênteses; sem isso a expansão textual produz erros sutis.

Código — macros.c
#include <stdio.h>

#define PI 3.14159
#define AREA_CIRCULO(r) (PI * (r) * (r))
#define SOMA(a, b) ((a) + (b))

int main(void)
{
    printf("PI = %.5f\n", PI);
    printf("area de raio 2 = %.5f\n", AREA_CIRCULO(2));
    printf("soma(3, 4) = %d\n", SOMA(3, 4));
    printf("com parenteses: SOMA(2, 3) * 2 = %d\n", SOMA(2, 3) * 2);
    return 0;
}
Saída esperada
PI = 3.14159
area de raio 2 = 12.56636
soma(3, 4) = 7
com parenteses: SOMA(2, 3) * 2 = 10

Macros embutidas: __func__, __LINE__, __FILE__, __DATE__

O pré-processador oferece macros automáticas: __FILE__ é o nome do arquivo, __LINE__ o número da linha, __func__ a função atual (isso daqui do compilador) e __DATE__/__TIME__ quando foi compilado. Excelente para logs leves:

Código — log-macro.c
#include <stdio.h>

#define LOG(msg) printf("[%s:%d] %s\n", __func__, __LINE__, msg)

int processar(void)
{
    LOG("processando...");
    return 0;
}

int main(void)
{
    LOG("inicio");
    processar();

    printf("Arquivo: %s\n", __FILE__);
    printf("Compilado em: %s %s\n", __DATE__, __TIME__);
    return 0;
}
Saída esperada
[main:13] inicio
[processar:7] processando...
Arquivo: log-macro.c
Compilado em: Sep 15 2026 16:21:01

(os números de linha, o nome do arquivo e a data dependem de onde você compila)

Stringizing (#) e token pasting (##)

# transforma o argumento em uma string literal; ## "cola" dois tokens para construir identificadores. Ferramentas raras, mas poderosas em meta-programação:

Código — stringize.c
#include <stdio.h>

#define STR(x) #x
#define CONCAT(a, b) a##b

int main(void)
{
    int carros = 3;

    printf(STR(carros) "\n");
    printf("carros = %d\n", CONCAT(car, ros));
    return 0;
}
Saída esperada
carros
carros = 3

Compilação condicional: #if, #ifdef, #else, #endif

Trechos inteiros de código podem nascer ou morrer na compilação. #ifdef X inclui o bloco se a macro X existir; #if avalia uma expressão; #undef apaga uma macro. Padrão típico: código de depuração que só é compilado com -DDEBUG:

Código — condicional.c
#include <stdio.h>

#define NIVEL 3

int main(void)
{
#if NIVEL >= 3
    printf("modo avancado ativo (NIVEL=%d)\n", NIVEL);
#else
    printf("modo basico\n");
#endif

#ifdef DEBUG
    printf("debug ligado\n");
#else
    printf("debug desligado\n");
#endif
    return 0;
}
Saída esperada
> gcc -Wall -Wextra -std=c11 condicional.c -o cond
> .\cond.exe

modo avancado ativo (NIVEL=3)
debug desligado

> gcc -DDEBUG -Wall -Wextra -std=c11 condicional.c -o cond2
> .\cond2.exe

modo avancado ativo (NIVEL=3)
debug ligado

Guardas de inclusão: o cabeçalho "anti-duplicado"

Quando dois arquivos .c incluem o mesmo .h (que por sua vez inclui outro), as declarações colariam duas vezes. A include guard — um #ifndef na primeira inclusão e #endif no fim — garante que o conteúdo seja colado uma única vez.

Este trecho é um cabeçalho (.h), não um programa completo; ele ganha vida ao ser #includeado pelos .c do módulo T2.09.

Código — contador.h (fragmento de cabeçalho)
#ifndef CONTADOR_H
#define CONTADOR_H

#define VALOR_INICIAL 0

int proximo(void);

#endif  /* CONTADOR_H */

Macros vs funções e a avaliação dupla

Macro é texto: os argumentos são colados sem avaliação. Se o argumento tem efeito colateral (++n) ou é uma chamada cara, a macro pode avaliá-lo mais de uma vez. Funções avaliam cada argumento uma única vez — prefira funções (e static inline) sempre que possível.

Código — dupla-evaluacao.c
#include <stdio.h>

#define MAX(a, b) ((a) > (b) ? (a) : (b))

int chamadas = 0;

int custoso(int v)
{
    chamadas++;
    return v;
}

int main(void)
{
    int r = MAX(custoso(7), custoso(3));

    printf("r = %d\n", r);
    printf("custoso foi chamado %d vezes (numa funcao seriam 2)\n", chamadas);
    return 0;
}
Saída esperada
r = 7
custoso foi chamado 3 vezes (numa funcao seriam 2)

✏️ Exercícios

Nível 1

Exercício 2.08.1

Defina #define TAXA 0.08 e um programa que calcula o preço com imposto de um valor lido do usuário. Imprima o resultado formatado.

Dica: Use scanf("%lf", &v) e depois printf("%.2f", v * (1 + TAXA)).

Ver solução
#include <stdio.h>

#define TAXA 0.08

int main(void)
{
    double preco;

    printf("Preco sem imposto: ");
    if (scanf("%lf", &preco) != 1) {
        return 1;
    }

    printf("Com imposto: %.2f\n", preco * (1 + TAXA));
    return 0;
}

Teste com 100: imprime 108.00.

Nível 2

Exercício 2.08.2

Defina a macro BUGADA QUADRADO_BUG(x) x * x e use em QUADRADO_BUG(2 + 3) — imprima para ver o erro — e depois a versão correta QUADRADO(x) ((x) * (x)) que dá o esperado (25).

Dica: A expansion textual: 2 + 3 * 2 + 3 = 11. É esse "+ 3 * 2" o problema.

Ver solução
#include <stdio.h>

#define QUADRADO_BUG(x) x * x
#define QUADRADO(x) ((x) * (x))

int main(void)
{
    printf("QUADRADO_BUG(2 + 3) = %d\n", QUADRADO_BUG(2 + 3));
    printf("QUADRADO(2 + 3)     = %d\n", QUADRADO(2 + 3));
    return 0;
}

Esperado: 11 (o bug) e 25 (correto). É a lição dos parênteses.

Nível 3

Exercício 2.08.3

Crie uma macro LOG_ERRO(msg) que imprime [erro em FUNCAO (linha N)]: msg usando __func__ e __LINE__. Chame-a dentro de duas funções diferentes e mostre que a localização muda.

Dica: #define LOG_ERRO(msg) printf("[erro em %s (linha %d)]: %s\n", __func__, __LINE__, msg).

Ver solução
#include <stdio.h>

#define LOG_ERRO(msg) printf("[erro em %s (linha %d)]: %s\n", __func__, __LINE__, msg)

int carregar(void)
{
    LOG_ERRO("falha ao ler arquivo");
    return -1;
}

int main(void)
{
    LOG_ERRO("tudo certo?");
    carregar();
    return 0;
}

O número da linha muda conforme a chamada — o pré-processador cola o valor real.

Nível 3

Exercício 2.08.4

Escreva um programa com #ifdef DEBUG imprimindo o valor de uma variável e #else imprimindo só o resultado. Compile uma vez sem flag e outra com -DDEBUG, mostrando comportamentos diferentes.

Dica: gcc -DDEBUG prog.c -o prog_db define a macro DEBUG na linha de comando.

Ver solução
#include <stdio.h>

int main(void)
{
    int soma = 2 + 3;

#ifdef DEBUG
    printf("DEBUG: soma calculada = %d\n", soma);
#endif

    printf("resultado = %d\n", soma);
    return 0;
}

Sem -DDEBUG só aparece "resultado = 5"; com -DDEBUG aparece também a linha de depuração.

Nível 4

Exercício 2.08.5

Use # e ## para criar uma macro DECLARA_E_USA(v, val) que declara int v = val; e imprime o nome da variável e seu conteúdo, juntando mesagens como DECLARA_E_USA(idade, 21).

Dica: `#` gera o nome; chame STR(idade) para imprimir o texto "idade".

Ver solução
#include <stdio.h>

#define NOME_VAR(v) #v

int main(void)
{
    int idade = 21;
    int nota = 9;

    printf("%s = %d\n", NOME_VAR(idade), idade);
    printf("%s = %d\n", NOME_VAR(nota), nota);
    return 0;
}

Colando tokens (##) você poderia construir identificadores, ex.: CONCAT(var, i) vira vari. Tente como extra.

❓ Verificação rápida

🏗️ Miniprojeto: Logger com macros

Construa um mini-logger: um cabeçalho log.h com guarda de inclusão definindo LOG_INFO, LOG_AVISO e LOG_ERRO que imprimem nível, função e linha (usa __func__/__LINE__), e um programa principal que simula uma "sessão" (iniciar, processar nota, encerrar) gravando no terminal. Crie também um modo com -DDEBUG que imprime valores extras.

Critérios de aceite

  • log.h com include guard e macros com parênteses.
  • Três níveis de log chamados em funções diferentes, mostrando localização.
  • Bloco #ifdef DEBUG adicionando saída extra sem quebrar o normal.
  • Compila sem e com -DDEBUG, sempre -Wall -Wextra limpos.
